1 / 6 · One observation

Explaining one prediction

A feature joins a SHAP explanation when we reveal its value for the person we are explaining. What changes when that value becomes known?

Use a transparent prediction equation with three inputs: ability A, neighborhood opportunity N, and experience E. Its output is annual earnings in thousands of dollars.

f(A,N,E)=40+10A+24AN+4E

Ability and experience range from 0 to 1. Neighborhood opportunity ranges from −1 to +1. In this illustrative model, an adverse neighborhood can channel ability into counterproductive endeavors: the negative interaction can outweigh ability’s positive main term.

The equation and people are constructed for teaching. The product AN is part of the model, not a fourth feature. We keep this prediction function fixed throughout.

2 / 6 · The reference prediction

Begin with no features revealed

We need complete inputs to run the model. Our background has eight reference people, covering every combination of low or high ability, adverse or favorable neighborhood, and low or high experience. Each row has equal weight.

Predict earnings for every background row, then average those predictions. The baseline is $47,000.

This average is the value we assign to knowing none of the selected person’s features. It averages model outputs, not observed earnings, and it does not use one person with average characteristics.

3 / 6 · One feature joins

Reveal ability; average over the rest

Copy this person’s ability, 1, into every background row. Keep neighborhood and experience together as they were in that row.

Predict every hybrid row with the same model, then average. The new average is $52,000. Its change from the baseline, +$5,000, is ability’s marginal contribution when it is revealed first.

This is “integrating out” the unrevealed features: we average the model’s predictions over their background values. Unrevealed inputs are still present in every row; they are not assigned zero to represent absence.

Zero is a legitimate low value in this example’s background, just as −1 is a legitimate adverse neighborhood value.

4 / 6 · Change the preceding group

What if neighborhood was already known?

For a second comparison, start with this person’s neighborhood, −1, fixed in every background row. Ability and experience still come from the background. Their average prediction is $35,000.

Now also fix ability to this person’s value. Keep the same rows and experience values, predict again, and average. The average becomes $28,000, a change of −$7,000.

Here the adverse context makes revealing this person’s ability lower the averaged prediction. This sign reversal comes from the interaction in our equation.

These two averages give one marginal contribution, after a particular preceding group. They do not yet give ability’s final SHAP value.

5 / 6 · Average the marginal contributions

Now calculate the SHAP value

In three of the six feature orders, ability joins before neighborhood. In the other three, it joins after neighborhood. Experience’s position does not change ability’s marginal here because experience enters additively.

For this person, ability’s two marginal contributions are +$5,000 and −$7,000. Their equally weighted average is −$1,000: ability’s SHAP value.

The SHAP value summarizes all preceding contexts. It can be different from the marginal contribution in the adverse neighborhood alone. Select another feature to inspect its calculation, or open the six orders.

6 / 6 · The complete explanation

From the baseline to this prediction

Repeat the calculation for all three features. Their final SHAP values add to the difference between the baseline and this person’s prediction.

The waterfall starts at $47,000. Positive contributions move right; negative contributions move left. Together they reach $30,000.

The values beside the feature names are the person’s inputs. The numbers on the bars are contributions to predicted earnings, in thousands of dollars. The rows are sorted by contribution magnitude; this is a display order, not a revealing order.

Choose another person above the figure, including the same high ability and experience in a favorable neighborhood. The baseline stays fixed because the model and background stay fixed.

The calculation we have been doing

For a person x and a revealed feature group S, copy that person’s values for the group into every background row. Keep the unrevealed values from the same row, predict with the fixed model, and average. With our eight equally weighted reference rows,

vx(S)=18∑r=18f(xS,b−S(r))

Revealing feature j changes this average by vx(S ∪ {j}) − vx(S). Its SHAP value averages that marginal contribution across equally weighted feature orders, exactly as in the earlier Shapley story.

Our example uses interventional background replacement: average over all reference rows, rather than filtering them to people who match the revealed characteristics. Changing the background or masking rule can change the explanation.

See the Python operation

The transparent equation lets us check the arithmetic. In a machine-learning application, the prediction function below can be replaced by an already fitted model’s predict method. The model remains fixed while SHAP explains its output.

import numpy as np
import shap

def predict(rows):
    ability, neighborhood, experience = rows.T
    return 40 + 10*ability + 24*ability*neighborhood + 4*experience

def coalition_value(revealed):
    hybrid = background.copy()
    hybrid[:, revealed] = x[revealed]
    return predict(hybrid).mean()

# Ability joins after neighborhood.
before = coalition_value([1])
after = coalition_value([1, 0])
marginal = after - before

masker = shap.maskers.Independent(
    background, max_samples=len(background)
)
explainer = shap.ExactExplainer(predict, masker)
explanation = explainer(x.reshape(1, -1))
shap.plots.waterfall(explanation[0])

Here background holds the eight reference rows and x is the selected person’s three inputs. The reproduction files define those arrays, enumerate every coalition, and verify the values against Python SHAP. Larger models use explainers suited to their model class and computational budget.

Inspect the final numbers

Numbers are rounded only for display; calculations use the stored values at full precision.

This is an illustrative prediction equation, with synthetic reference people and chosen coefficients. It is not an estimated earnings equation or evidence about causal neighborhood effects. The positive ability–neighborhood interaction encodes complementarity; negative opportunity allows it to work against productive earnings.
