2 / 13 · The value function

The game assigns a prediction to each group

The symbol vx names the value function for our prediction game. It takes a group of features and returns the value we assign to that group.

Here that value is an average prediction: fix the group’s inputs to the observation we want to explain, and average the model’s predictions over background values for the other inputs. This gives vx(S).

With every feature fixed to the observation, this average is the model’s prediction itself. With only some features fixed, it is the prediction average for that partial information.

3 / 13 · The observation x

Whose prediction are we explaining?

The subscript x identifies one observation: the complete input row for the person whose prediction we want to explain. Its feature values are already known to us.

We use those values in the coalition thought experiment. Each included feature is fixed to its value in x; each excluded feature is averaged over the background. The same person supplies the fixed values throughout this game.

Another observation defines another game vx, even when the model and background stay the same.

4 / 13 · The existing group S

Which features are already fixed?

The set S is the coalition of features already fixed to this observation. The expression vx(S) is the average prediction before we add another feature.

The set F contains all the model’s input features, and m is their number. The sum considers the possible groups S that leave out the feature we are about to add.

The group can be empty. Then no columns are fixed to the observation, and the value is the background average prediction.

5 / 13 · The additional feature i

Now one more feature joins

The symbol i identifies the additional feature whose contribution we want to measure. It is not already in S. Adding it gives S ∪ {i}.

For vx(S ∪ {i}), keep the features in S fixed and also fix feature i to its value in x. The other features retain their background values.

Subtract vx(S) to get the additional feature’s marginal contribution. The two averages differ in exactly which columns are fixed: S before, S ∪ {i} after.

6 / 13 · The feature’s credit

The result is credit for feature i

On the left, ϕi(vx) is the Shapley value assigned to that additional feature in this observation’s game. It is the feature’s final contribution to the prediction, measured in the model output’s units.

The sum on the right averages its marginal contributions across possible preceding groups S. The factorials give the same order weights as in the earlier Shapley story.

We can now compute those terms. We will choose one person, hold the prediction model fixed, and use background rows to show what each value-function expression does.

7 / 13 · The model and the observation

Train the model; explain one prediction

In a machine-learning application, training data contain features X and observed outcomes y. Fitting learns a prediction function f. SHAP then uses that fixed function to explain its prediction f(x) for one observation x.

We supply a transparent teaching equation so you can check each prediction. Its players are ability a, neighborhood opportunity n, and experience e: F = {a, n, e} and m = 3. Lowercase letters name individual features; uppercase F and S name sets of features. It predicts annual earnings in thousands of dollars.

f(a,n,e)=40+10a+24an+4e

Ability and experience range from 0 to 1; neighborhood opportunity ranges from −1 to +1. An adverse neighborhood can make the interaction outweigh ability’s positive main term. The product an belongs inside f; it is not a fourth player.

This equation and the reference people are constructed for teaching, rather than estimated from earnings data. The steps that follow also apply to a fitted model. All three of the focal person’s inputs are known: “revealing” one is the coalition thought experiment we use to assign credit.

8 / 13 · The term vₓ(S)

What is the value of a feature group?

To define vx(S), fix the columns in S to this person’s values. For the excluded columns, keep the values from each background row. Run every complete row through the fixed model and average the predictions.

Start with S = ∅: none of the person’s columns are fixed. Our eight equally weighted reference rows cover every combination of low or high ability, adverse or favorable neighborhood, and low or high experience. Their average prediction is $47,000, so vx(∅) is the baseline.

Background rows define the reference distribution. They may be drawn from training inputs, but here they are used to average predictions. Their observed outcomes are not needed, and the model is not fitted again for each feature group.

The empty coalition’s value is not zero. It is the prediction average with no columns fixed to this person. Adding no feature leaves any group unchanged: S ∪ ∅ = S.

9 / 13 · The term vₓ(S ∪ {i})

Add the person’s ability to the group

Here S = ∅ and i = a. The term vx(S ∪ {i}) therefore becomes vx({a}). Copy this person’s ability, 1, into every background row. Keep neighborhood and experience together as they were in that row.

Run these hybrid inputs through the same model and average the outputs. The new value is $52,000. Subtract vx(∅) to get +$5,000: ability’s marginal contribution to this prediction when no other feature is fixed.

This is “integrating out” the excluded features: we average predictions over their background values. Every model call still uses all three columns. Included means fixed to this person; excluded means averaged over the background.

Zero is a legitimate input value in these rows. It is not how we represent an excluded feature.

10 / 13 · The difference vₓ(S ∪ {i}) − vₓ(S)

Change S; compare the same two terms

Now take S = {n}, keeping i = a. Fix this person’s neighborhood, −1, in every background row. Ability and experience remain at their background values. The average, vx({n}), is $35,000.

Add ability to that group: fix both columns to this person, retaining experience from each row. The average, vx({a, n}), is $28,000. Subtract the two means to get −$7,000.

Here the adverse context makes revealing this person’s ability lower the averaged prediction. This sign reversal comes from the interaction in our equation.

The subtraction in the Shapley formula is exactly this comparison of prediction averages. Each preceding group S produces one marginal contribution; the formula then weights and adds them.

11 / 13 · The factorial weight

How often does each group precede ability?

For three features there are 3! = 6 equally weighted revealing orders. Here |S| is the number of features in S. A particular preceding group S appears in |S|!(3 − |S| − 1)! of them: arrange the features in S before ability, and the remaining features after it.

Divide that count by six. The empty group gets weight 0!2!/3! = 2/6; each one-feature group gets 1!1!/3! = 1/6; the two-feature group gets 2!0!/3! = 2/6.

The table puts each weight beside the two prediction averages it multiplies. Those are the same averages we computed by fixing columns and predicting background rows. No new operation is hidden in the factorials.

Open the six orders to see the preceding groups counted directly.

12 / 13 · The sum and its result

Add the weighted marginal contributions

The sum visits all four groups that exclude ability. Weight each prediction difference by the fraction of orders in which that group precedes ability, then add. This gives ϕa(vx), ability’s SHAP value for this observation.

We can combine equal contributions in this example. Before neighborhood is fixed, ability contributes +$5,000 with total weight 2/6 + 1/6 = 3/6. After neighborhood is fixed, it contributes −$7,000 with total weight 1/6 + 2/6 = 3/6. The result is −$1,000.

Experience’s position does not change ability’s marginal here because experience enters additively. Select another feature to inspect its average, or open the six orders. The formula assigns credit for the model’s prediction; it does not estimate a causal effect of changing a person’s features.

13 / 13 · From the formula to the plot

From the baseline to this prediction

Repeat the same Shapley calculation for each feature. With every column fixed, all hybrid rows equal this person’s inputs, so vx(F) = f(x). The SHAP values add to the difference f(x) − vx(∅).

The waterfall starts at $47,000. Positive contributions move right; negative contributions move left. Together they reach $30,000.

The values beside the feature names are the person’s inputs. The numbers on the bars are SHAP contributions to predicted earnings, in thousands of dollars. The rows are sorted by contribution magnitude; this is a display order, not a revealing order.

Choose another person above the figure. The game’s coalition values and SHAP values change with x, while the model, background, and baseline stay fixed.

The calculation we have been doing

For a person x and a revealed feature group S, copy that person’s values for the group into every background row. Keep the unrevealed values from the same row, predict with the fixed model, and average. With our eight equally weighted reference rows,

vx(S)=18∑r=18f(xS,b−S(r))

Revealing feature i changes this average by vx(S ∪ {i}) − vx(S). Its SHAP value averages that marginal contribution across equally weighted feature orders, exactly as in the earlier Shapley story.

Our example uses interventional background replacement: average over all reference rows, rather than filtering them to people who match the revealed characteristics. Changing the background or masking rule can change the explanation.

See the Python operation

The transparent equation lets us check the arithmetic. In a machine-learning application, the prediction function below can be replaced by an already fitted model’s predict method. The model remains fixed while SHAP explains its output.

import numpy as np
import shap

def predict(rows):
    ability, neighborhood, experience = rows.T
    return 40 + 10*ability + 24*ability*neighborhood + 4*experience

def coalition_value(revealed):
    hybrid = background.copy()
    hybrid[:, revealed] = x[revealed]
    return predict(hybrid).mean()

# Ability joins after neighborhood.
before = coalition_value([1])
after = coalition_value([1, 0])
marginal = after - before

masker = shap.maskers.Independent(
    background, max_samples=len(background)
)
explainer = shap.ExactExplainer(predict, masker)
explanation = explainer(x.reshape(1, -1))
shap.plots.waterfall(explanation[0])

Here background holds the eight reference rows and x is the selected person’s three inputs. The reproduction files define those arrays, enumerate every coalition, and verify the values against Python SHAP. Larger models use explainers suited to their model class and computational budget.

Inspect the final numbers

Numbers are rounded only for display; calculations use the stored values at full precision.

This is an illustrative prediction equation, with synthetic reference people and chosen coefficients. It is not an estimated earnings equation or evidence about causal neighborhood effects. The positive ability–neighborhood interaction encodes complementarity; negative opportunity allows it to work against productive earnings.
