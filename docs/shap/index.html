1 / 20 · Start with Shapley

From Shapley values to SHAP

The players are now a model’s input features. What is the game whose Shapley values explain a prediction?

Begin with the familiar formula. We will connect its parts to a two-feature election model, then use an earnings interaction to see why a feature’s contribution can depend on the group it joins.

φi⁡(vx)= ∑S⊆F∖{i} |S|!(m−|S|−1)!m! [vx⁡(S∪{i})−vx⁡(S)]

2 / 20 · The observation x

Whose prediction are we explaining?

The symbol x identifies one observation: the complete input row whose prediction we want to explain. It can describe an election or a person. Its feature values are already known to us.

When we fix a feature, its value comes from this row. We keep those inputs the same within each explanation.

The subscript in vx keeps track of which observation we are explaining. Another observation can have a different explanation, even with the same prediction model.

3 / 20 · The prediction ŷ

The model predicts an outcome

A fitted model takes a complete input row x and predicts its outcome: ŷ(x) = f(x). The hat distinguishes the prediction ŷ from an observed outcome y.

Observed outcomes help fit the model. Once fitted, the same model can predict the complete rows we construct for a SHAP explanation. We will average those predictions.

We are explaining a predicted outcome. A prediction error would compare an observed outcome with its prediction; that is a different quantity.

4 / 20 · The value function

The game assigns a prediction to each group

Now vx names the value function for this observation’s prediction game. It takes a group of features and returns the value we assign to that group.

Here that value is an average prediction: fix the group’s inputs to x, and use reference input rows, called the background, for the other inputs. Average the model outputs ŷ over these complete rows to get vx(S). It is not a prediction error.

With every feature fixed, the average is the observation’s prediction itself, ŷ(x) = f(x). With only some features fixed, vx(S) is the average of the predictions over the hybrid rows.

5 / 20 · The existing group S

Which features are already fixed?

The set S is the coalition of features already fixed to this observation. The expression vx(S) is the average prediction before we add another feature.

The set F contains all the model’s input features, and m is their number. The sum considers the possible groups S that leave out the feature we are about to add.

The group can be empty. Then no columns are fixed to the observation, and the value is the background average prediction.

6 / 20 · The additional feature i

Now one more feature joins

The symbol i identifies the additional feature whose contribution we want to measure. It is not already in S. Adding it gives S ∪ {i}.

For vx(S ∪ {i}), keep the features in S fixed and also fix feature i to its value in x. The other features retain their background values.

Subtract vx(S) to get the additional feature’s marginal contribution. The two averages differ in exactly which columns are fixed: S before, S ∪ {i} after.

7 / 20 · The feature’s credit

The result is credit for feature i

On the left, ϕi(vx) is the Shapley value assigned to that additional feature in this observation’s game. It is the feature’s contribution to the difference between the model’s prediction and the background average prediction, measured in the model output’s units.

With the model and background held fixed, we can also write this as ϕi(x): the feature’s SHAP contribution for observation x.

The sum on the right averages its marginal contributions across possible preceding groups S. The factorials give the same order weights as in the earlier Shapley story.

We can now compute those terms. Start with a two-feature election model, hold its fitted coefficients fixed, and watch what excluding a feature means.

8 / 20 · Three correlations

Bread, peace, and a predicted vote

Douglas Hibbs’s Bread and Peace model uses real income growth and war fatalities to predict the incumbent party’s two-party presidential vote share. We use those two features in a stylized OLS example.

Center and standardize income growth, war fatalities, and the observed vote share y: each has mean zero and standard deviation one. We can describe the OLS fits with just three correlations.

The feature correlation is ρ = −0.5. Income’s correlation with observed vote is +0.75; fatalities’ correlation with observed vote is −0.75. These describe the observed outcome y, which we use to fit the prediction model.

The correlations are chosen for teaching, rather than estimated from historical elections. Hibbs’s original model also estimates income-growth time weights; this warm-up uses direct two-feature OLS.

9 / 20 · The OLS fits

The correlations determine three models

In a univariate regression with both the feature and outcome standardized, the slope equals their correlation. Income-only OLS therefore predicts 0.75 × income; fatalities-only OLS predicts −0.75 × fatalities.

With both features included, adjust each feature–vote correlation for the other feature and divide by 1 − ρ². The two slopes are

bincome=0.75−(−0.5)(−0.75)1−(−0.5)2=0.5
bfatalities=−0.75−(−0.5)(0.75)1−(−0.5)2=−0.5

The bivariate model is ŷ(x) = 0.5 × income − 0.5 × fatalities. Centering makes every fitted intercept zero. Predictions use the outcome’s SD units; they are not themselves rescaled to SD one.

We will explain this bivariate model. The two univariate fits help us see what would change if we actually removed a feature and refitted OLS.

10 / 20 · One election’s prediction

Keep the bivariate model fixed

Take the growth, lower fatalities profile: income 1 and fatalities −1. Its bivariate prediction is 1 SD of incumbent-party vote share. We write ŷ(income, fatalities) to display both inputs to that model.

For the prediction game, “include income” means keep this election’s income and average over the reference fatalities. We use their overall mean, zero, regardless of the fixed income. Because this model is additive and linear, the average equals predicting with fatalities at that mean. The result is 0.5.

Income-only OLS instead predicts 0.75. Its coefficient absorbs the omitted-variable term: 0.75 = 0.5 + (−0.5)(−0.5). Our SHAP calculation keeps the bivariate coefficients and changes the inputs being supplied to the model.

Here F = {income, fatalities} and m = 2. The inputs are standardized: +1 is one SD above the mean and −1 one below it. Negative standardized fatalities mean fewer fatalities than average.

11 / 20 · Income first

Reveal income, then fatalities

Start with neither feature fixed. Both inputs average to zero, giving the baseline vx(∅) = ŷ(0, 0) = 0.

Income joins the empty group. Replace its mean, zero, with this election’s income, 1. Fatalities stay averaged to zero. Subtract the prediction before income joins from the prediction after it joins: the marginal is +0.5.

Fatalities then join {income}. Keep income fixed and replace mean fatalities with this election’s value, −1. The prediction changes from 0.5 to 1, giving fatalities a marginal of +0.5.

Every subtraction is vx(S ∪ {i}) − vx(S), written here as two evaluations of the same bivariate prediction equation. Averaging excluded inputs is what makes the partially fixed prediction a coalition value.

12 / 20 · Fatalities first

Reverse the revealing order

Return to the same zero baseline. This time fatalities join first, while income remains averaged to zero. The prediction becomes 0.5, giving fatalities a marginal of +0.5.

Income then joins {fatalities}. Keep this election’s fatalities fixed and replace mean income with its value, 1. Subtract the fatalities-only coalition value from the full prediction. Income’s marginal is +0.5.

Both orders use the same coefficients and the same averaging rule. Because the model has no interaction, a feature’s marginal is the same whichever group it joins. Correlation between the features does not add a term to these fixed-model subtractions.

13 / 20 · The two-feature SHAP values

Average across the two orders

With two features there are 2! = 2 equally weighted orders. For each feature, average its marginal when it joins first and its marginal when it joins second. Each receives weight 1/2.

In our background-replacement game, an additive linear model with a centered background gives ϕi(x) = bixi. Here income contributes +0.5 and fatalities contribute +0.5. Baseline plus the two contributions equals the prediction.

Now add an interaction in a different example. The prediction game and background-row operation stay the same, but a feature’s marginal can depend on which other features are already fixed.

14 / 20 · The model and the observation

When features interact

Now explain a person’s predicted earnings with three features and an interaction. In a machine-learning application, fitting learns a prediction function f from input rows X and outcomes y. SHAP then explains ŷ(x) = f(x) while holding that function fixed.

We supply a transparent teaching equation so you can check each prediction. Its features are ability, neighborhood opportunity (written as neighborhood), and experience: F = {ability, neighborhood, experience} and m = 3. It predicts annual earnings in thousands of dollars.

f(x)=40+10×ability +24×ability×neighborhood +4×experience

Ability and experience range from 0 to 1; neighborhood opportunity ranges from −1 to +1. An adverse neighborhood can make the interaction outweigh ability’s positive main term. The product ability × neighborhood belongs inside f; it is not a fourth player.

This equation and the reference people are constructed for teaching, rather than estimated from earnings data. The steps that follow also apply to a fitted model. All three of the focal person’s inputs are known: “revealing” one is the coalition thought experiment we use to assign credit.

For the adverse neighborhood profile, ability is 1, neighborhood opportunity is −1, and experience is 1. The model predicts $30,000 per year.

15 / 20 · The term vₓ(S)

What is the value of a feature group?

To define vx(S), fix the columns in S to this person’s values. For the excluded columns, keep the values from each background row. Run every complete row through the fixed model and average the predictions.

Start with S = ∅: none of the person’s columns are fixed. Our eight equally weighted reference rows cover every combination of low or high ability, adverse or favorable neighborhood, and low or high experience. Their average prediction is $47,000, so vx(∅) is the baseline.

Background rows define the reference distribution. They may be drawn from training inputs, but here they are used to average predictions. Their observed outcomes are not needed, and the model is not fitted again for each feature group.

Here the empty coalition’s value is 47, rather than the centered OLS warm-up’s zero. In both cases it is the prediction average with no columns fixed to the observation. Adding no feature leaves any group unchanged: S ∪ ∅ = S.

16 / 20 · The term vₓ(S ∪ {i})

Add the person’s ability to the group

Here S = ∅ and i = ability. The term vx(S ∪ {i}) therefore becomes vx({ability}). Copy this person’s ability, 1, into every background row. Keep neighborhood and experience together as they were in that row.

Run these hybrid inputs through the same model and average the outputs. The new value is $52,000. Subtract vx(∅) to get +$5,000: ability’s marginal contribution to this prediction when no other feature is fixed.

This is “integrating out” the excluded features: we average predictions over their background values. Every model call still uses all three columns. Included means fixed to this person; excluded means averaged over the background.

Zero is a legitimate input value in these rows. It is not how we represent an excluded feature.

17 / 20 · The difference vₓ(S ∪ {i}) − vₓ(S)

Change S; compare the same two terms

Now take S = {neighborhood}, keeping i = ability. Fix this person’s neighborhood, −1, in every background row. Ability and experience remain at their background values. The average, vx({neighborhood}), is $35,000.

Add ability to that group: fix both columns to this person, retaining experience from each row. The average, vx({ability, neighborhood}), is $28,000. Subtract the two means to get −$7,000.

Here the adverse context makes revealing this person’s ability lower the averaged prediction. This sign reversal comes from the interaction in our equation.

The subtraction in the Shapley formula is exactly this comparison of prediction averages. Each preceding group S produces one marginal contribution; the formula then weights and adds them.

18 / 20 · The factorial weight

How often does each group precede ability?

For three features there are 3! = 6 equally weighted revealing orders. Here |S| is the number of features in S. A particular preceding group S appears in |S|!(3 − |S| − 1)! of them: arrange the features in S before ability, and the remaining features after it.

Divide that count by six. The empty group gets weight 0!2!/3! = 2/6; each one-feature group gets 1!1!/3! = 1/6; the two-feature group gets 2!0!/3! = 2/6.

The table puts each weight beside the two prediction averages it multiplies. Those are the same averages we computed by fixing columns and predicting background rows. No new operation is hidden in the factorials.

Open the six orders to see the preceding groups counted directly.

19 / 20 · The sum and its result

Add the weighted marginal contributions

The sum visits all four groups that exclude ability. Weight each prediction difference by the fraction of orders in which that group precedes ability, then add. This gives ϕability(vx), ability’s SHAP value for this observation.

We can combine equal contributions in this example. Before neighborhood is fixed, ability contributes +$5,000 with total weight 2/6 + 1/6 = 3/6. After neighborhood is fixed, it contributes −$7,000 with total weight 1/6 + 2/6 = 3/6. The result is −$1,000.

Experience’s position does not change ability’s marginal here because experience enters additively.

Select another feature to inspect its average, or open the six orders. The formula assigns credit for the model’s prediction; it does not estimate a causal effect of changing a person’s features.

20 / 20 · From the formula to the plot

From the baseline to this prediction

Repeat the same Shapley calculation for each feature. With every column fixed, all hybrid rows equal this person’s inputs, so vx(F) = ŷ(x) = f(x). The complete prediction is ŷ(x) = vx(∅) + ∑iϕi(x): baseline plus feature contributions.

The waterfall starts at $47,000. Positive contributions move right; negative contributions move left. Together they reach $30,000.

The values beside the feature names are the person’s inputs. The numbers on the bars are SHAP contributions to predicted earnings, in thousands of dollars. The rows are sorted by contribution magnitude; this is a display order, not a revealing order.

Choose another person above the figure. The game’s coalition values and SHAP values change with x, while the model, background, and baseline stay fixed.

The calculation we have been doing

For an observation x and a revealed feature group S, copy that observation’s values for the group into every background row. Keep the unrevealed values from the same row, predict with the fixed model, and average. The earnings example uses eight equally weighted reference rows:

vx(S)=18∑r=18f(xS,b−S(r))

Here b(r) is reference row r, xS supplies the observation’s values for columns in S, and −S denotes all the other columns. Together, (xS, b(r)−S) specifies one complete hybrid input row, with every value in its original column.

Revealing feature i changes this average by vx(S ∪ {i}) − vx(S). Its SHAP value averages that marginal contribution across equally weighted feature orders, exactly as in the earlier Shapley story.

Both examples use interventional background replacement: average over all reference rows, rather than filtering them to observations that match the revealed characteristics. Excluded columns stay together from the same reference row, preserving their dependence with one another; they are not conditioned on the fixed inputs. Changing the background or masking rule can change the explanation.

Why refitting and conditional averaging are different

Removing fatalities and refitting OLS changes the income coefficient. The omitted-variable identity compares that new coefficient with the full-model coefficient. Our SHAP calculation instead keeps the full fitted model and averages over the background fatality distribution.

Conditional SHAP is another possible game: it averages excluded features using their distribution conditional on the included values. Correlated features can then share credit differently, even in a linear model. That still keeps the prediction model fixed; it is not refitting a reduced model. See SHAP’s linear-model explanation.

In the additive OLS warm-up, averaging predictions equals predicting with excluded features at their means. The row-averaging definition also works for nonlinear and interaction models, where substituting a single mean row need not reproduce the average prediction.

See the Python operation

The transparent equation lets us check the arithmetic. In a machine-learning application, the prediction function below can be replaced by an already fitted model’s predict method. The model remains fixed while SHAP explains its output.

import numpy as np
import shap

def predict(rows):
    ability, neighborhood, experience = rows.T
    return 40 + 10*ability + 24*ability*neighborhood + 4*experience

def coalition_value(revealed):
    hybrid = background.copy()
    hybrid[:, revealed] = x[revealed]
    return predict(hybrid).mean()

# Ability joins after neighborhood.
before = coalition_value([1])
after = coalition_value([1, 0])
marginal = after - before

masker = shap.maskers.Independent(
    background, max_samples=len(background)
)
explainer = shap.ExactExplainer(predict, masker)
explanation = explainer(x.reshape(1, -1))
shap.plots.waterfall(explanation[0])

Here background holds the eight reference rows and x is the selected person’s three inputs. The reproduction files define those arrays, enumerate every coalition, and verify the values against Python SHAP. Larger models use explainers suited to their model class and computational budget.

Inspect the final numbers

Numbers are rounded only for display; calculations use the stored values at full precision.

The earnings equation uses synthetic reference people and chosen coefficients. It is not an estimated earnings equation or evidence about causal neighborhood effects. The positive ability–neighborhood interaction encodes complementarity; negative opportunity allows it to work against productive earnings.
