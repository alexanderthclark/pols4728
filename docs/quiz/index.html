POLS 4728 / Quiz explained

Prediction, selection, and causal adjustment

Searching many random predictors can produce a perfect validation score. Closely spaced training observations can produce unstable predictions despite low outcome noise. Estimating a tutoring effect requires separating evaluation from fitting and adjusting outcomes and treatment consistently.

Question 1 / 6 points

Selecting among random predictors

There are 20 observations and 32,768 candidate predictors. Every prediction is a fair coin flip. Searching among so many candidates changes the score we can find on the selection data, while leaving performance on unused observations at chance.

Read Question 1

We have 20 total observations with a target y∈{0,1}20. Suppose there are 215 random predictors that are random vectors X∈{0,1}20 with each element drawn iid from Bernoulli(0.5). We consider each predictor to be a “model” with no training parameters so that y^=Xk for the model that uses predictor k. The goal is to pick a single model, meaning we select a single predictor.

  1. What is the expected test accuracy of each of these candidate predictors?
  2. Describe a plausible model selection and evaluation procedure. Should any data be devoted to training?
  3. Would a nested validation strategy be useful for part (b)?

Question 1(a)

Fair guesses have 50% expected test accuracy

A fair prediction matches a fixed 0 or 1 equally often, so the target need not be balanced. The selected predictor also has 50% expected test accuracy, provided selection and tie-breaking use only the validation observations. A small test set can give a realized score far from 50%.

Read the calculation and assumptions

At any unused observation, a Bernoulli(0.5) prediction matches either target label with probability one half. The target need not be balanced: a fair prediction matches a fixed 0 and a fixed 1 equally often.

E[test accuracy]=12

The same expectation holds for the predictor we select, provided selection and tie-breaking use only the validation observations. With only 10 test observations, the realized score can differ substantially from 50%. Its standard deviation is 0.5×0.510≈0.158, or about 15.8 percentage points.

Question 1(b)

Select on validation, then test once

No parameters need training. Use 10 observations to choose a predictor and reserve 10 for evaluation. Searching 32,768 independent candidates yields 32 perfect validation predictors on average, yet expected accuracy on the untouched test observations remains 50%. Moving the split changes selection opportunities and test precision, not predictive information.

Read the calculation and assumptions

There are no coefficients or other parameters to fit, so a separate training set serves no purpose here. One plausible procedure randomly assigns 10 observations to validation and 10 to a final test set. Select the predictor with the highest validation accuracy, resolve ties by a rule fixed in advance, and report its accuracy on the untouched test set.

A particular predictor is perfect on all 10 validation observations with probability 2−10. Across 32,768 independent candidates, we expect 32 perfect validation predictors. The chance of finding at least one is

1−(1−2−10)32768≈1.

A nearly certain 100% validation score can therefore coexist with 50% expected test accuracy. The validation result has been selected from thousands of attempts. Looking again at test results to select another predictor would make those observations part of the selection process too.

With 10 validation observations, 32 perfect candidates are expected. Ten untouched test observations remain.

Question 1(c)

Evaluate the selection procedure on outer folds

Hold out an outer fold, select a predictor on the other observations, and score that choice on the held-out fold. Repeat and average. Different folds may select different predictors. This evaluates the selection procedure; it is optional when an untouched final test set is available, and either estimate is noisy with only 20 observations.

Read the calculation and assumptions

Nested evaluation can hold out an outer fold, use all remaining observations to choose a predictor, and evaluate that choice on the outer fold. Repeating across outer folds and averaging the held-out accuracies assesses the procedure that searches among candidates. Different outer folds may choose different predictors.

An additional inner training/validation split is unnecessary because these candidates have no fitted parameters. The inner observations can all be used for selection. An untouched final test set already provides valid evaluation, so nested evaluation is optional here. Neither strategy creates predictive information, and either estimate will be noisy with only 20 observations.

Question 2 / 14 points

Comparing three age predictors

The conditional mean age is μ(x)=x. Although outcome noise is smaller at low x, estimating a slope from nearby training observations can amplify that noise. Flooring predictions adds bias and can create large jumps near reporting thresholds.

Read Question 2

Three carnies predict age Y, measured in days, using a single predictor X.

Y=X+ε

where ε∣X=x∼N(0,x100)1. Suppose that in the population X∼Unif[0,730]. The first carnie fits an OLS model using a stratified sampling strategy: his training sample contains two observations, X=0 and another with X=730. The second carnie uses a sample with X=0 and X=1, because he figures his estimator will suffer from less variance because the irreducible noise is lower at low X values. The third tries to employ shrinkage. He uses the first carnie's predictions, but reports only feasible whole-year ages of 0, 365, or 730 days. He rounds each prediction down to the nearest multiple of 365, truncating predictions below 0 to 0 and predictions above 730 to 730.

  1. Plot each carnie's y^(x) for 10 independent, simulated training data sets.
  2. Analytically, compare the bias and variance of the first two carnies predictions for any fixed x.
  3. Numerically/by simulation, compare the bias and variance of the first and third carnies, averaged over all X.
  4. Which carnie will have the lowest expected MSE for a random X? Would this change if Var[ε∣X]=mX100 where m is a large constant?

Question 2(b)

A wider training interval stabilizes the slope

Both fitted lines are unbiased for the conditional mean. At every positive test age, Carnie 2’s prediction variance is 730 times Carnie 1’s; both variances are zero at the origin. Lower outcome noise is overwhelmed by dividing that noise by a one-day training interval and extrapolating across the population.

Read the calculation and assumptions

Holding the test value x fixed, repeat the training sample. The fitted prediction is y^(x;a)=x+xaεa. Since the training error has mean zero, both Carnies 1 and 2 are unbiased for μ(x)=x. Their prediction variance is

Question 2(c) / Detail near a reporting threshold

Flooring creates jumps at reporting thresholds

Near 365 days, a tiny fitting difference can change the whole-year report by 365 days. Carnie 1’s variance at that age is 1.825 days²; Carnie 3’s is approximately 33,306.25 days². The detail panels intentionally use different vertical scales. Compressing differences within a reporting bin does not guarantee lower variance across its boundary.

Read the calculation and assumptions

Away from a threshold, different fitted lines often produce the same whole-year report. Near a threshold, a tiny difference between lines can change that report by 365 days. At x=365, Carnie 1’s prediction variance is

365273000=1.825days².

Carnie 3 reports almost equally often 0 or 365 at this age. Its variance is therefore approximately

36524=33306.25days².

The detail views intentionally use different vertical scales to make both changes visible. Flooring collapses differences within a year bin but expands differences across its boundary. Moving predictions toward zero does not by itself guarantee lower variance.

Question 2(d) / Larger noise variance

Large noise can change the ranking

Retain normal errors while multiplying their variance by m. Carnies 1 and 2’s prediction errors grow with m, while Carnie 3’s reports remain bounded between 0 and 730. Carnie 3 eventually wins, though moderate noise increases need not change the ranking. The common outcome-noise contribution is included; the figure uses a logarithmic scale.

Read the calculation and assumptions

Retain the normal-error assumption, now with ε∣X=x∼N(0,mx100). Multiplying the noise variance by m multiplies Carnies 1 and 2’s prediction variances and the common irreducible noise by m. Their expected prediction MSEs become 6.0833m and 1779.9833m. Carnie 2 cannot beat Carnie 1 for any positive m.

Question 3 / 16 points

Adjusting for pre-tutoring scores

Tutoring adds 10 points to every student’s outcome. We first examine fitting and evaluating the outcome model on the same students. Then we consider observational data, where students with higher baseline scores receive tutoring more often.

Read Question 3

A researcher studies tutoring's effect on final exam scores Yi. Let Xi be a continuous pre-tutoring score and Di∈{0,1} indicate tutoring. Suppose the causal relationship is

Yi=50+401{Xi≥60}+10Di.

The researcher predicts Y from X alone and proposes estimating the tutoring effect using adjusted outcomes after partialing out X:

Ri=Yi−y^(Xi),τ^=R¯D=1−R¯D=0.

Question 3(a)(i)

Memorization makes every in-sample residual zero

With distinct pre-tutoring scores and one student per leaf, the tree reproduces every observed outcome. The in-sample residual R=Y−y^(X) is zero for every student, so the proposed treatment estimate is zero rather than 10. Excluding treatment from the predictor list does not prevent the tree from memorizing each student’s treatment contribution.

Read the calculation and assumptions

A full-sample tree with one student per leaf predicts each observed outcome exactly. Thus y^(Xi)=Yi, every adjusted outcome is zero, and

τ^=0−0=0.

This misses the true 10-point tutoring effect. Distinct pre-tutoring scores let the tree identify individual students and reproduce their outcomes, including the contribution of treatment. Excluding D from the predictor list does not prevent the outcome model from memorizing that contribution.

Question 3(a)(ii)

Held-out adjustment preserves the expected effect

Fit the tree on training students and compare adjusted outcomes only on held-out students. Conditional on the fitted tree, random assignment makes the expected baseline adjustment equal in both evaluation groups, preserving the 10-point expected effect when both groups are represented. A small evaluation group or unstable tree can still yield an imprecise estimate.

Read the calculation and assumptions

An evaluation student’s outcome did not determine the fitted tree. Perfect training prediction therefore does not force that student’s residual to zero. Conditional on the fitted tree, random assignment gives both evaluation treatment groups the same distribution of pre-tutoring scores in expectation.

Write f(X)=50+401{X≥60}. The adjusted outcome is R=f(X)−y^(X)+10D. The first two terms have the same expected value in both treatment groups, so their difference cancels and the expected adjusted difference is 10, provided both groups are represented.

This is an expectation over repeated assignments and evaluation samples. A small evaluation group may have unequal baseline scores by chance. An unstable tree can leave substantial residual variation, and holding out observations reduces the sample used for the comparison. Valid evaluation therefore does not guarantee a precise or exactly correct realized estimate.

Question 3(b)(i)

The observed gap combines baseline and treatment differences

Tutoring adds 10 points to every student, so the ATE is 10. Yet the tutored students average 90 and the untutored students average 60. More tutored students have high baseline scores: that composition difference contributes 20 points to the observed 30-point gap.

Read the calculation and assumptions

The outcome equation says that tutoring adds 10 points for every student, so the ATE is 10. The observational treatment groups have different compositions: 12 of 16 tutored students have high pre-tutoring scores, compared with 4 of 16 untutored students.

Y¯D=1=4(60)+12(100)16=90
Y¯D=0=12(50)+4(90)16=60

The observed difference is 30 points: the causal effect of 10 plus a 20-point baseline difference, 40(0.75−0.25). Comparing the raw means attributes this baseline composition difference to tutoring.

Question 3(b)(ii)

The outcome tree learns two group means

A split at 55 yields outcome predictions of 52.5 for low scores and 97.5 for high scores. Their 45-point difference contains the 40-point baseline difference plus 5 points from differing tutoring rates. Subtracting these leaf means therefore removes some treatment-related variation as well as baseline variation.

Read the calculation and assumptions

A squared-error regression tree splits between scores 50 and 60; use the midpoint 55. Scores 40 and 50 have the same mean outcome, as do scores 60 and 70, so further splits do not improve squared error. Each leaf contains 16 students.

The low-score leaf predicts 12(50)+4(60)16=52.5; the high-score leaf predicts 4(90)+12(100)16=97.5.

Question 3(b)(iii)

Outcome adjustment alone gives 7.5

After subtracting the outcome-tree predictions, tutored students average 3.75 and untutored students average −3.75. Their difference is 7.5, below the 10-point causal effect. Comparing these outcome residuals with the original treatment indicator does not account for the treatment-related variation removed by the outcome adjustment.

Read the calculation and assumptions

The treated students’ mean adjusted outcome is 4(7.5)+12(2.5)16=3.75. The untutored students’ mean is 12(−2.5)+4(−7.5)16=−3.75. Thus

τ^=3.75−(−3.75)=7.5.

This does not recover the ATE of 10. The outcome tree subtracts a larger average tutoring contribution in the high-score group, where tutoring is more common. Comparing the residuals using the original treatment indicator does not account for how that adjustment changes treatment-related variation.

Question 3(b)(iv) / The weighted calculation

The count-weighted regression recovers 10

Count every student when summing across the four combinations. The adjusted-treatment squares sum to 6, and the treatment–outcome products sum to 60. Regressing the adjusted outcome on adjusted treatment without an intercept therefore gives 60 ÷ 6 = 10. Both sides now use the same remaining variation within score groups.

Read the calculation and assumptions

Use the counts when summing across the four combinations. The denominator of the regression through the origin is

∑iTi2=12(0.252)+4(0.752)+4(0.752)+12(0.252)=6.

Because each adjusted outcome is ten times its adjusted treatment, the numerator is ∑iTiRi=10∑iTi2=60. The estimated effect is

τ^=606=10points.

Adjusting treatment removes its association with the pre-tutoring score group. Regressing the adjusted outcome on the adjusted treatment compares the same remaining variation on both sides, recovering the tutoring effect in this example.
