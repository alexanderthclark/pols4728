# Midterm Short Answers

Scrollytelling explanations of all seven short-answer questions from the Fall 2026 POLS 4728 midterm. The original questions are preserved in expandable panels, and added numerical illustrations are labeled.

Live URL: https://alexanderthclark.github.io/pols4728/midterm/

This directory is a self-contained static site. All scripts, fonts, artwork, and KaTeX assets use relative paths. GitHub Pages publishes it through the existing course workflow. The course homepage intentionally has no link to this explainer.

The published files reproduce the reviewed 90-step version, including the title illustration, reversible scroll states, optional exploration controls, reduced-motion support, and reading view.
