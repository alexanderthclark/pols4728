# Transformers: the residual stream

A scrolling architecture lesson with one attention layer containing two heads
and one shared, position-wise MLP. An opening overview compares an encoder and a
decoder before the walkthrough follows their residual streams. Attention
matrices are taken as given; the lesson does not explain queries and keys.

Public address: https://alexanderthclark.github.io/pols4728/transformers/

The lesson is intentionally not linked from the course homepage. GitHub Pages
publishes this directory with the rest of `docs/` after the repository checks
pass on `main`.

The page is static HTML, CSS, and JavaScript. Its fonts, math renderer, and active
title illustration are local. Scroll forward or backward to move through the
lesson; navigation links and ordinary keyboard scrolling remain available.
Reduced-motion preferences show completed states at the same scroll positions.
