Meta-learners: DR and R

Use doubly robust pseudo-outcomes or an orthogonal residual loss to learn a conditional effect function.

The shared example contains 80 constructed observations at five engagement values. Each value has 16 observations; treatment counts match the stated propensities and outcome noise is balanced within each treatment arm. The conditional effect is 6−4x. Small least-squares and penalized least-squares fits are actually calculated; they illustrate learning architectures, not a ranking of methods on research data. Later sensitivity examples are identified separately.

4 / 18 · Build the DR learner

Fit an effect learner to the pseudo-outcomes.

A second-stage regression learns their conditional mean. The linear fit here recovers the decreasing effect function.

τ^DR=arg⁡min⁡f∈F∑i[ϕ^i−f(Xi)]2\widehat\tau_{\mathrm{DR}}=\arg\min_{f\in\mathcal F}\sum_i[\widehat\phi_i-f(X_i)]^2τDR​=argf∈Fmin​i∑​[ϕ​i​−f(Xi​)]2

The DR-learner uses a regression method with pseudo-outcomes as its response and covariates as inputs. The final model can differ from the nuisance learners. Our least-squares fit with features 1,x1,x1,x returns coefficients 6 and −4. This calculation uses specified first-stage predictions and balanced data to isolate the second-stage operation; it is not evidence that a particular effect learner is optimal.

5 / 18 · Build the DR learner

The second-stage function class still matters.

Restrict the final regression to a constant. It returns 4 and misses the heterogeneity, even though the pseudo-outcomes have the right conditional mean.

F={f(x)=c}⟹τ^DR(x)=4\mathcal F=\{f(x)=c\}\quad\Longrightarrow\quad\widehat\tau_{\mathrm{DR}}(x)=4F={f(x)=c}⟹τDR​(x)=4

Double robustness concerns nuisance misspecification in the pseudo-outcome's conditional mean. It does not make an unsuitable final regression consistent for a varying CATE. A constant fit estimates an average of these targets. A richer final learner must still have enough data and appropriate complexity control to approximate and estimate the conditional effect function.

Correct pseudo-outcome mean does not guarantee a correct fitted curve.

9 / 18 · Double robustness

Build each pseudo-outcome from held-out predictions.

Fit the two outcome means and propensity outside each fold. Use their predictions to construct pseudo-outcomes for that fold.

ϕ^i=ϕ(Wi;η^(−k)),i∈Ik\widehat\phi_i=\phi(W_i;\widehat\eta^{(-k)}),\qquad i\in I_kϕ​i​=ϕ(Wi​;η​(−k)),i∈Ik​

A simple analysis uses one sample for nuisance fitting and an independent sample for effect regression. Cross-fitting extends this idea by rotating nuisance-training and held-out folds. Tuning and preprocessing stay inside the nuisance-training data for each fold. The assembled pseudo-outcomes can then train an effect model, but that model still needs separate evaluation. Cross-fitting does not by itself establish CATE accuracy, rate conditions, or confidence intervals.

Nuisance cross-fitting is distinct from final model evaluation.

A quotient needs its matching squared weight.

A small treatment residual can make a divided target enormous. The equivalent weighted problem gives that observation a small squared weight.

15 / 18 · Understand the loss

Poor overlap flattens the effect-learning objective.

When treatment is nearly predictable, changing the candidate effect barely changes the residual loss. There is little local information about the effect.

LR(f)−LR(τ)=E[e(X)(1−e(X))(f(X)−τ(X))2]L_R(f)-L_R(\tau)=\mathbb E[e(X)(1-e(X))(f(X)-\tau(X))^2]LR​(f)−LR​(τ)=E[e(X)(1−e(X))(f(X)−τ(X))2]

With true nuisance functions, excess population residual loss is a treatment-variance-weighted squared effect error. Where 0<e(x)<10<e(x)<10<e(x)<1, an unrestricted function class has minimizer τ(x)\tau(x)τ(x). Where treatment is deterministic, this loss carries no information about the local effect. A restricted function class instead targets an overlap-weighted approximation; it need not minimize unweighted CATE error or return the ATE. The plot varies local eee from 0.5 to 0.03.

18 / 18 · Evaluate the full procedure

Reserve data for comparing effect learners.

On this known-nuisance construction, the correct curve has residual loss 1; a constant effect of 4 gives 1.39; a zero-effect curve gives 4.89.

LR(f)=E[(Y−ℓ(X)−(D−e(X))f(X))2]L_R(f)=\mathbb E[(Y-\ell(X)-(D-e(X))f(X))^2]LR​(f)=E[(Y−ℓ(X)−(D−e(X))f(X))2]

The three displayed candidates are fixed in advance, and these losses are computed exactly using known nuisances. For data-dependent candidates in research, evaluate the full procedure on held-out observations using suitably trained nuisance predictions and a criterion aligned with the scientific target. Cross-fitted nuisance predictions do not make an effect model's training performance an independent assessment. CATE uncertainty needs its own theory; scalar AIPW standard errors and root-n conclusions do not automatically apply to a fitted effect curve.
