We follow one constructed socks-and-shoes head throughout. First, it matches a destination to a source and mixes position values to produce a task score. Then we generalize the scalar query–key calculation, show how its output can update a representation, and change the setting to left-to-right prediction with a causal mask. The original task has access to both items; its target scores are not claims about the later masked calculation. The parameters are chosen to make every step inspectable.

The exact socks-and-shoes model

The target is 0 for socks before shoes and −1 for shoes before socks. Each input row contains a socks indicator, a shoes indicator, and a position value: +1 in the first slot and −1 in the second. This is a constructed model with fixed parameters, not a pretrained language model.

We form by adding token embeddings and position vectors of the same width. Position embeddings can be learned without reserving a coordinate. For this example, we choose fixed vectors: the token embeddings are zero in the third coordinate, and the position vectors are zero in the first two. We follow this one construction through the calculation.

Queries and keys read token identity; values carry position. With , the score matrix is . Shoes assigns 75% to socks and 25% to itself. The socks row is uniform. All weights come from finite softmax scores.

Swapping the token order preserves the identity-based matching rule while changing which position is carried by each token. The mean output changes from +0.25 to −0.25, giving predictions 0 and −1. Removing positional information or using uniform attention gives −0.5 for both orders. This exact solution covers the two sequences shown; it does not demonstrate generalization to arbitrary clothing sequences.

From a constructed head to a pretrained model

A useful next step is Neel Nanda’s pretrained one-layer attention-only model. Its configuration has eight parallel attention heads and no feed-forward network in the layer. Embeddings, positional information, normalization, and a prediction readout remain. One layer need not mean one head.

The current lesson computes its constructed examples in the browser. It does not display measurements from that checkpoint or GPT-2. Those models can provide a later comparison using actual tokenization, attention weights, and continuation probabilities.

Sources and conventions

Nelson Elhage and colleagues (2021), A Mathematical Framework for Transformer Circuits, especially “Attention Heads as Information Movement,” the QK/OV decomposition, and the tensor-product appendix. The distinction between moving information across positions and transforming it within each position motivates this lesson.

Simon J. D. Prince (2023), Understanding Deep Learning, chapter 12, §§12.2–12.3, equations 12.6–12.9. Prince stores tokens as columns. We transpose the convention: projection matrices multiply from the right, attention multiplies from the left, and softmax normalizes each row. The paper’s per-token maps likewise transpose when translated into this convention.

Additional visual reference: Grant Sanderson, Attention in transformers, step-by-step. Its emphasis on what information a destination seeks and how values change a representation informs this sequence. That lesson uses column vectors; this one retains tokens as rows.
