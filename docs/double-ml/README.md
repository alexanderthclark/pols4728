# Double Machine Learning for Beginner's

The standalone lesson begins with a constructed tutoring example, then briefly
introduces nuisance predictions, orthogonality, and cross-fitting. The randomized
memorization and single-holdout illustrations are separate from the observational
32-student calculation. The displayed group-mean calculation is not cross-fitted.

The pinned stage is controlled by scroll position. `story.js` renders each pose
from `scrollState` in `model.mjs`; elapsed time never advances an explanation.
Keep the same student IDs through regrouping and both residual adjustments.
Outcome subtraction precedes the residual-axis zoom. The tutoring axis first
makes room for negative values, then subtraction moves every student left.
Scrolling backward restores those states. Reduced motion uses the same scene
progress with meaningful endpoint poses.

Follow the repository design guide's scrollytelling requirements. Before delivery,
verify actual forward and backward scrolling, intermediate coordinates, pinning,
label readability, keyboard controls, and reduced motion on desktop and narrow
screens. Holding the page still must also hold the diagram still. Mathematical
tests cover the 30-point raw gap, 7.5-point outcome-only gap, weighted residual
slope of 10, stable observations, and reversible progress; browser verification
is needed in addition to those tests.

The further-reading links in the page cite Ahrens and colleagues' introduction
and Arif's guide for ecologists. No external charting or animation runtime is
required.
