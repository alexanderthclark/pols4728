Inspect the experiment

What was actually trained?

A scalar input, one hidden ReLU layer, and a linear output; all weights and biases are trained using plain SGD with no momentum, weight decay, or early stopping. The outcomes are noiseless steps. These are illustrative runs, not a benchmark of the best achievable fit.

The 2,048 fixed inputs are evenly spaced midpoints of [−1, 1], with labels y = 1 when x > 0 and y = 0 otherwise. There is no label noise and no deliberately empty interval around the jump. Each epoch shuffles the entire dataset without replacement into 32 batches of 64. Each run lasts 300 epochs: 9,600 updates and 614,400 observation visits.

The hidden-layer parameters are θ: θⱼ₁ multiplies the input for neuron j and θⱼ₀ is its bias. The output-layer parameters are φ: φⱼ multiplies hidden output hⱼ(x), and φ₀ is the shared output bias. Thus f(x; θ, φ) = φ₀ + Σⱼ φⱼ ReLU(θⱼ₀ + θⱼ₁x). With two hidden neurons, θ has four entries and φ has three. The combined gradient has seven components and both collections update together, using derivatives evaluated at the same current model.

The learning rate is αₜ = 0.05/(1 + t/6000). The animations use seed 1 for both widths, with matched batch order; the table reports every seed from 1 to 8. Input weights are uniform on [−1, 1], hidden biases on [−0.5, 0.5], output weights on [−1, 1]/√m, and the output bias starts at 0.5. Initialization and shuffling use separate seeded random streams.

The training objective is half the mean squared error: average one-half times each squared residual within the batch. Here a residual is prediction minus target. A batch of 64 observations has a vector of 64 residuals, one per observation. Its loss is a single number, but the loss function depends on the seven model parameters. The parameter gradient has seven components: each measures how the loss changes as one parameter changes, with the others held fixed. It combines the batch’s residuals according to how that parameter affects the predictions. For the output bias φ₀, every prediction changes by the same amount, so its gradient is simply the mean residual, −0.1681 for this batch. The other parameters affect predictions differently, so their gradient components use different contributions from those same residuals. All components are evaluated at the same current weights. The scalar φ₀ calculation previews one component of the first update; the next scene applies that same update to the entire parameter vector together. A zero gradient leaves its parameter unchanged.

The performance plots and table report ordinary MSE over all 2,048 training observations. Ordinary MSE is twice the half-MSE objective. Grid MSE uses 4,000 evenly spaced midpoints of [−1, 1]. Width 12 has 37 parameters versus seven at width 2; both have one hidden layer. Update count and data visits are held fixed, while wider updates cost more computation. For these eight seeds, every width-12 run improves on its paired width-2 run.

The first two batches are explained individually, followed by the remaining 30 updates. The first two epochs are recorded in full so the transition to the second pass preserves the exact learned weights. Later epochs skip forward through recorded checkpoints, with the current batch highlighted. Within a displayed update, the animation interpolates between the actual before-and-after parameters. Full-data loss can rise on an individual minibatch update.

After the width-2 run finishes, the parameter inspection varies one final parameter at a time within ±0.02, holding the other six fixed. Every trial starts from the same model after 9,600 updates; these are hypothetical changes, not additional SGD steps. Its curve and ordinary MSE use all 2,048 training observations, and the endpoint table keeps the resulting losses for all seven parameters visible. Its two columns report MSE after decreasing or increasing the named parameter by 0.02; they are not MSE differences. A separate readout labels the moving trial’s current MSE and its change from baseline. Tiny loss improvements remain possible, but these small changes leave the broad transition. This inspection does not establish that the fitted parameters are an exact local minimum.

For the original ramp with shared input slope k, H(0) = 0, the integrated absolute error is 1/(2k), and the supremum error on any interval containing points immediately to the right of zero is 1 for every finite k. This does not contradict UAT’s uniform-approximation statement for continuous targets.
