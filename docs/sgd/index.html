The hidden weight and bias act inside the ReLU.

Inspect the experiment

What was actually trained?

A scalar input, one hidden ReLU layer, and a linear output; all weights and biases are trained using plain SGD with no momentum, weight decay, or early stopping. The outcomes are noiseless steps. These are illustrative runs, not a benchmark of the best achievable fit.

The 2,048 fixed inputs are evenly spaced midpoints of [−1, 1], with labels y = 1 when x > 0 and y = 0 otherwise. There is no label noise and no deliberately empty interval around the jump. Each epoch shuffles the entire dataset without replacement into 32 batches of 64. Each run lasts 300 epochs: 9,600 updates and 614,400 observation visits.

The learning rate is 0.025/(1 + t/6000). The animations use seed 1 for both widths, with matched batch order; the table reports every seed from 1 to 8. Input weights are uniform on [−1, 1], hidden biases on [−0.5, 0.5], output weights on [−1, 1]/√m, and the output bias starts at 0.5. Initialization and shuffling use separate seeded random streams.

Training loss is mean squared error over all 2,048 observations. Grid MSE uses 4,000 evenly spaced midpoints of [−1, 1]. Width 12 has 37 parameters versus seven at width 2; both have one hidden layer. Update count and data visits are held fixed, while wider updates cost more computation. For these eight seeds, every width-12 run improves on its paired width-2 run.

The first-epoch animation replays all 32 actual updates. Later epochs skip forward through recorded checkpoints, with the current batch highlighted. Within a displayed update, the animation interpolates between the actual before-and-after parameters. Full-data loss can rise on an individual minibatch update.

The sharp reference fits use hand-chosen parameters. For the original ramp, H(0) = 0, the integrated absolute error is 1/(2a), and the supremum error on any interval containing points immediately to the right of zero is 1 for every finite a. This does not contradict UAT’s uniform-approximation statement for continuous targets.
