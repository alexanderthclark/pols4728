Width of Two is Mathematically Sufficient

A shallow ReLU network with two hidden neurons can represent a ramp approximation to the step. As its slope increases, the transition narrows. The target f(x)f(x)f(x) stays fixed while the teal approximation becomes steeper; the finite-slope network remains continuous.

Stochastic gradient descent

  1. Set the initial parameters.
  2. Choose a batch and calculate its loss.
  3. Calculate the gradient of the batch loss.
  4. Update all parameters opposite the gradient, scaled by the learning rate.
  5. Repeat steps 2–4 with new batches.

Other settings: batch size, maximum epochs, and regularization strength. Early stopping ends training after a chosen number of epochs without enough improvement on validation data.

Initialize once. For each batch, evaluate the loss and its gradient at the current parameters. The gradient gB=∇(θ,ϕ)LBg_B=\nabla_{(\theta,\phi)}L_BgB​=∇(θ,ϕ)​LB​ is one vector, with one partial-derivative component per parameter. Update all parameters together in the opposite direction, with the learning rate α\alphaα setting the step size. Then repeat with a new batch. The gradient changes as both the batch and the current parameters change.

Early stopping uses held-out validation data. The validation fraction, minimum improvement, and patience control when training ends. The experiment shown later instead uses a fixed 300-epoch run.
