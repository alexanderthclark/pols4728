# Training neural networks

A 28-scene, scroll-driven POLS 4728 lesson. The title states the goal, and a standalone static slide introduces the data-generating process before any neurons: 2,048 evenly spaced inputs between −1 and 1, with outcomes exactly zero for x ≤ 0 and one for x > 0. There is no noise. A large typeset equation sits alongside the step and representative actual observations. It then constructs a step approximation from two separate ReLUs, transforms their input weights and hidden biases, flips one output contribution, adds them, and applies the shared output bias. The dashed gray target appears as soon as the combined network output is revealed and remains the reference throughout training and comparison.

Notation follows the course notes: θⱼ₁ is an input weight, θⱼ₀ a hidden bias, φⱼ an output weight, and φ₀ the output bias. The prediction is f(x; θ, φ), and α is the learning rate. At width 2, the combined seven-component gradient covers four hidden-layer θ parameters and three output-layer φ parameters; both collections update from the same current model. Internal model storage retains `w`, `b`, `a`, and `c`, respectively, so notation changes do not alter the recorded training trajectory.

The main SGD chapter opens with a transition and a diagram partitioning the actual 2,048 observations into 32 disjoint batches of 64. It selects the first batch, follows one observation's prediction and half-squared-error loss, adds the 64 point losses, and divides by 64 to obtain the half-MSE batch loss. A paired diagram distinguishes the 64 residuals indexed by observations from the seven gradient components indexed by parameters. Each component describes how the batch loss changes with one parameter, combining residuals according to that parameter’s effect on predictions. The output bias provides a concrete example: it shifts every prediction equally, so its gradient is the mean residual. The complete gradient appears together at the same current model; no backpropagation derivation is required. The width-12 scene reinforces that the same 64 observations give 64 residuals but 37 parameter-gradient components. A scalar-axis preview explains the output-bias component of the first update, then the next scene applies that same update to the whole model. A table shows all seven parameter values moving at the same update fraction as the curve; the inactive first neuron's three zero-gradient entries remain unchanged. The earlier hand-chosen construction is explicitly distinguished from SGD, and its shared input slope uses k to avoid confusion with the output weights φ₁ and φ₂.

The next batch uses the learned weights to compute a new loss, gradient, and update. The animation then speeds through batches 3–32, completes the first epoch, reshuffles the same observations, and performs the first update of epoch two. Learned weights remain continuous across these scenes. A lap-style counter at the bottom right shows the current epoch and the number of completed batch updates in that pass; it advances to the next epoch only after all 32 updates are complete.

After width 2 finishes 300 epochs, a separate inspection varies each of its seven parameters by up to ±0.02, one at a time. Each trial starts from the exact final model and holds the other six parameters fixed; it never changes the recorded experiment or counts as another SGD update. The curve and ordinary full-data MSE are recomputed for every displayed perturbation, while a table retains both endpoint losses for all seven parameters. Its columns explicitly report resulting MSE after −0.02 and +0.02 parameter nudges, separately from the moving trial’s current MSE and change from baseline. The fitted function is written out in full, and parameter labels use the bundled KaTeX renderer. The broad fit remains, although tiny loss improvements are possible; this is not a claim of an exact local minimum. Scrolling backward restores the same trials, and reduced motion retains the complete table.

`batches.html` remains a separate, focused seven-scene introduction to batches and epochs. Its small teaching example groups 12 numbered observations into three batches of four, follows one complete pass, then reshuffles the same observations for another epoch. It ends by connecting these definitions to the actual experiment's 2,048 observations and 32 batches; it does not include the loss and gradient calculations or the training counter.

The experiment uses 2,048 evenly spaced noiseless observations and plain minibatch SGD. Each epoch shuffles all observations into 32 batches of 64. Both shallow widths (2 and 12) train for 300 epochs with matched batch order and learning-rate schedule. The training objective is half-MSE and the learning rate is `0.05 / (1 + step / 6000)`. This is exactly equivalent to the previous ordinary-MSE objective with a `0.025` initial rate: every parameter update and final prediction is preserved. Performance plots and result tables continue to report ordinary MSE; batch calculations explicitly report half-MSE. `loss()` evaluates the objective and `mse()` evaluates the metric. For compatibility, the recorded trace `loss`/`afterLoss` and run `loss` fields remain ordinary MSE; `firstUpdate.batchBefore`/`batchAfter` are half-MSE objectives. Seed 1 is replayed for each width; all eight fixed seeds appear in the results table. The first two epochs are recorded in full so the transition between passes preserves the exact model and batch order. Later training accelerates through recorded checkpoints. Animation interpolates only between actual before/after parameters at a recorded update.
