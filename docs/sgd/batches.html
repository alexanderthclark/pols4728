Stochastic gradient descent

First, two ideas: batches and epochs.

How do we organize the data while a model learns?

Start with the training data.

Imagine a small dataset with 12 observations. Each tile stands for one input and its target.

The numbers identify observations; they are not the target values.

A batch is one small group.

Choose a batch size of 4. Divide these 12 observations into three groups of four.

Each outlined group is one batch. We use one batch for each learning step.

Use one batch, then the next.

Use a batch to adjust the model, then move to the next batch. Keep the adjustments as you go.

Watch the count: 4, then 8, then all 12 observations have been used.

One complete pass is one epoch.

All 12 observations have now been used once. Finishing all three batches completes the first epoch.

A batch is one group. An epoch is one full pass through the dataset.

Same observations. A new pass.

For the next epoch, reshuffle the same observations into new batches. Every observation gets another turn.

Keep the model’s learned weights. Only the data order and the count within the epoch restart.

The same idea with more data.

Our training dataset has 2,048 observations. With batches of 64, one complete epoch contains 32 batches.

The 12-tile example made the grouping visible. The meaning of batch and epoch stays the same.

Batches and epochs

One group. One complete pass.

  • A batch is a group of observations used for one learning step.
  • An epoch is one complete pass through the training dataset.

In the small example, 12 observations form three batches of four. Using all three batches completes one epoch. The next epoch reuses the same observations in a new order and keeps what the model has learned.

In our training experiment, 2,048 observations form 32 batches of 64. Every observation is used once per epoch.
