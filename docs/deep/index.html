What does another layer add?

From broad ramps to local features.

A point has two inputs, x1 and x2. A network assigns it one numeric response, y. The height of this surface is that response.

Keep three familiar ReLU features fixed. Give them to one additional hidden layer. Watch the new layer build features that respond within a bounded region.

2 / 8 · One hidden layer

Three familiar ramps

Each first-layer unit applies ReLU to a linear function of the inputs. Its surface bends along a straight line in the input plane.

h1,1=a[x1] h1,2=a[x2] h1,3=a[−x1−x2]

Here a[z] = max(0, z). Select a unit to see its ramp and activation boundary. These three features will stay fixed for the rest of the story.

3 / 8 · An affine output

Combine the ramps

A shallow network can weight these features and add a bias. Choose a bias of 1 and a weight of −1 on each feature.

yshallow=1−h1,1−h1,2−h1,3

The surface peaks at the origin and slopes down away from it. It crosses zero along the dashed hexagon, then continues to negative values.

Its slope changes lie on the original straight crease lines. Changing the output weights can change those slopes.

4 / 8 · Insert a second hidden layer

Give the features to new units

Replace the shallow readout with another layer of three hidden units. Each new unit receives all three first-layer activations directly.

h2=a[β1+Ω1h1]

Following Prince, β denotes biases and Ω denotes weights. The activation acts on each unit separately.

For the first new unit, choose the same weighted combination we just saw. Before its ReLU, the surface is unchanged. Now there is another nonlinear operation to apply.

5 / 8 · Apply the new ReLU

A response confined to one region

h2,1=a[1−h1,1−h1,2−h1,3]

The new ReLU clips every negative value to zero. What remains is a hexagonal tent: a local feature with a peak of 1 and an exactly zero response outside its footprint.

The dashed outline now marks an activation boundary. It bends as it crosses the first layer’s regions. The original crease lines terminate at that outline because the surface outside it is flat.

Select an input point in the small plot to follow its activations through the network.

6 / 8 · A different combination

Pinch one flank

h2,2=a[1−2h1,1−h1,2−h1,3]

At the default weight of −2, the second new unit puts more negative weight on the first feature. Wherever h1,1 is active, its preactivation falls faster. That side of the footprint contracts. A weaker negative weight expands it.

Move the weight control. The first-layer ramps stay fixed while the new feature’s shape changes.

7 / 8 · The output surface

Combine three local features

The third new unit gives the second first-layer feature a weight of −2. It pinches another flank. All three second-layer units now contribute to an affine output.

y=h2,1+0.3h2,2+0.3h2,3

Different footprints introduce different crease segments into the final surface. Depth has let the network build nonlinear features from existing nonlinear features, then recombine them.

There are two hidden layers, each with three units. The output is linear; there is no third hidden layer.

8 / 8 · Keep the first layer fixed

Explore the geometry

Inspect the shallow readout, an individual new feature, or the combined output. Change the weight and trace an input point through the same network.

The comparison has a precise scope. With these three first-layer features fixed, a shallow affine readout is affine along every ray from the origin. It cannot form this peak and then remain exactly zero farther out. The added ReLU can.

This is a construction of representational capacity. We chose the weights to make the geometry clear; we have not trained a model or compared test error.

Prince’s folding viewpoint describes how a layer changes the geometry of its inputs. Here we follow a complementary consequence: a new unit can combine those features into a response active within a local region.

The model and its scope

This original example uses the notation of Simon J. D. Prince’s Understanding Deep Learning, Chapter 4, especially §4.3. The parameters below are chosen for illustration. The first layer remains fixed; the second hidden layer has three units with separately specified incoming weights.

Show the complete network

With elementwise ReLU a[z] = max(0, z):

h1=a[β0+Ω0x] β0=0,Ω0=[1001−1−1] h2=a[β1+Ω1h1] β1=[111],Ω1=[−1−1−1−c−1−1−1−2−1]

The default is c = 2. The weight control changes only c.

y=β2+Ω2h2,β2=0,Ω2=[10.30.3]

Why hold the first features fixed? Along a ray r x, with r ≥ 0, these bias-free first-layer features satisfy h₁(r x) = r h₁(x). Any affine readout of them is affine in r. It cannot be nonzero near the origin and identically zero beyond a finite distance along every ray. The second-layer ReLU supplies that extra change in slope. This argument concerns these fixed features; it is not a parameter-matched comparison with arbitrary shallow networks.

The input window is [−1.6, 1.6]². At the default weights, all three local features are zero outside the displayed hexagonal footprint, including beyond this window. At the control’s weakest negative weight, one flank can extend beyond the displayed window.
