What does another layer add?

One input. More places to bend.

A network takes one number, x, and predicts one number, y. Its predictions trace a curve.

Start with three familiar ReLU units. Add one more hidden layer with three units. Follow where the new bends come from.

Scroll to build the curve, or use Next.

2 / 8 · One hidden layer

Three ramps, three hinges

Each unit starts rising at a different input. Its ReLU creates one hinge: at 0, 1, or 2.

h1,1=a[x] h1,2=a[x−1] h1,3=a[x−2]

Here a[z] = max(0, z). The three hinges divide the input line into four intervals. Within each interval, all three features are straight-line functions of x.

These first-layer features stay fixed throughout.

3 / 8 · An affine output

Make the curve turn

A shallow network weights the ramps and adds a bias. Choose weights that make the curve rise, fall, then rise again.

q1=−0.5+h1,1−2h1,2+2h1,3

This could be the shallow network’s output. Its bends remain at 0, 1, and 2. Reweighting fixed ramps changes slopes, but cannot introduce a bend inside one of those intervals.

The curve also crosses zero three times. A zero crossing alone is not a bend.

4 / 8 · Add a second hidden layer

Use that sum inside a new unit

Each new unit receives all three first-layer activations. It weights them, adds its own bias, and applies another ReLU.

h2=a[β1+Ω1h1]

Following Prince, β denotes biases and Ω denotes weights. For the first new unit, choose exactly the sum q1 we just saw.

Before its ReLU, the curve is unchanged. Notice the crossings at 0.5, 1.5, and 2.5. Each sits inside an existing first-layer interval.

5 / 8 · Apply the new ReLU

Crossings become bends

h2,1=a[q1]

ReLU sets every negative value to zero. At each zero crossing, the curve now joins a flat segment. Its slope changes there: a new bend.

One new unit has introduced bends at 0.5, 1.5, and 2.5, even though the first layer’s hinges have not moved.

Clipping can also remove a bend. The old hinges at 0 and 2 lie in regions that are now flat. The bend at 1 survives.

6 / 8 · A second new unit

Move a threshold, move three bends

h2,2=a[−τ+h1,1−3h1,2+4h1,3]

The second new unit uses different weights. Its bias is −τ. Raise the threshold τ and its preactivation shifts down, moving all three zero crossings.

Within the middle interval, its preactivation is 3 − τ − 2x. The new bend is therefore at (3 − τ)/2. It moves while the first-layer hinges remain at 0, 1, and 2.

7 / 8 · An affine output

Combine the new features

The third new unit uses another combination:

h2,3=a[−0.6+h1,1−1.5h1,2+h1,3]

The output combines the three second-layer activations:

y=h2,1+0.3h2,2+0.3h2,3

At the default threshold, the output has ten bends. Each new unit contributes its own crossings. Only one of the original hinges survives.

Two hidden layers, three units in each. The output is affine.

8 / 8 · Trace the same network

Explore where it bends

Choose a curve, change the threshold, or select an input. Follow that one number through the network.

A shallow network with three hidden ReLU units and an affine output has at most three bends. Our two-layer example has ten at the default weights. It has more parameters, too; a sufficiently wide shallow network could reproduce this curve.

Prince’s folding example shows how repeated transformations can reuse pieces of a function. Here the visible consequence is new zero crossings inside old intervals. Applying ReLU turns those crossings into new bends.

The weights are chosen to show this mechanism. We have not trained a model or compared prediction error.

The model and its scope

This scalar-input construction follows the notation of Simon J. D. Prince’s Understanding Deep Learning, Chapter 4. The new units directly recombine the three first-layer activations, using distinct weight vectors. All displayed curves come from these same chosen parameters.

Show the complete network

h1 = a[β0 + Ω0x], with β0 = (0, −1, −2)T and Ω0 = (1, 1, 1)T.

β1=[−0.5−τ−0.6],Ω1=[1−221−341−1.51]

h2 = a[β1 + Ω1h1]. The default threshold is τ = 0.3; the control changes only this bias, over 0.2 ≤ τ ≤ 0.8.

y = β2 + Ω2h2, with β2 = 0 and Ω2 = (1, 0.3, 0.3).

The default output has bends at 0.3, 0.5, 0.6, 1, 1.35, 1.5, 1.8, 2.2, 2.5, 2.65. There are eleven linear intervals in the displayed window [−0.25, 3.25]. When two new crossings coincide, the number of distinct bends falls.

Each hidden unit in a scalar-input shallow ReLU network creates at most one hinge. With an affine output, width three therefore allows at most three bends. This comparison holds width fixed, with a larger parameter count for the two-layer model. It demonstrates representational capacity for chosen weights, rather than training success or better test error.
