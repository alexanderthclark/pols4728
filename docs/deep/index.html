More joints, fewer parameters

Fold the input. Reuse a pattern.

One input, x. One prediction, y. This curve has ten joints: ten places where its slope changes.

2 / 8 · One hidden layer

One unit buys one joint

A scalar-input ReLU unit has one hinge. With an affine output, a shallow network with D hidden units can therefore have at most D joints.

These three units provide familiar ramps:

h1,1=a[x] h1,2=a[x−1] h1,3=a[x−2]

Here a[z] = max(0, z). Count an input weight, hidden bias, and output weight for each unit, plus one output bias: 3D + 1 parameters.

3 / 8 · Prepare the fold

Forward, backward, forward

Weight the ramps so their combination rises, falls, then rises again.

q=h1,1−2h1,2+2h1,3

On [0, 1], q = x. On [1, 2], q = 2 − x. On [2, 3], q = x − 2.

All three intervals cover the same range of q, from 0 to 1. The middle interval runs through it in reverse.

Three intervals lie on top of one another

Think of the input line folding back at 1 and again at 2. Three different inputs can now have the same folded coordinate.

For example, x = 0.25, 1.75, 2.25 all give q = 0.25. The solid rows represent the three input intervals, positioned by q. Dotted guides link two drawings of the same endpoint at x = 1 or x = 2; they contain no additional inputs.

5 / 8 · Add the second hidden layer

One downstream joint appears three times

h2,2=a[q−0.5]

This new unit has one hinge in the folded coordinate: q = 0.5. Unfold the input line and that hinge appears at three input positions:

x=0.5,1.5,2.5

Use the input slider to follow x across these joints. Each crossing comes from the same threshold in q.

q is the weighted combination entering the new units. It adds no extra neuron; the network has three units in each of two hidden layers.

6 / 8 · Three downstream units

Three joints become nine

The new units have fixed thresholds of 0.2, 0.5, and 0.8. Each threshold cuts all three overlapping pieces of the input line.

h2,j=a[q−τj]

Weight their outputs to make one small pattern in q:

g(q)=h2,1−2h2,2+2h2,3

The complete prediction is y = g(q(x)). We reuse the same downstream pattern three times, reversing its middle copy.

7 / 8 · Compare the same curve

Ten joints from 22 parameters

The final curve has nine copied joints, plus the surviving turn at x = 1. The turn at 2 disappears because all three new units are flat near q = 0.

8 / 8 · The value of reuse

The copies share their joints

Move the input slider to follow x through the fold, one new unit, the pattern in q, or the full curve. Inputs with the same folded coordinate receive the same prediction.

The parameter saving comes with structure. Each downstream threshold sets a joint in all three input intervals. The copied joints are linked; we cannot position all ten independently. Depth is economical here because the same pattern occurs repeatedly.

This example establishes an exact representation with fewer parameters. Its weights are chosen to make the fold clear; it does not compare training or prediction error.

The model and the parameter count

This original scalar-input construction follows Simon J. D. Prince’s Understanding Deep Learning, Chapter 4: folding in §4.1, composition as a two-layer network in §4.2, and linear regions per parameter in §4.5.2.

Show the complete network and exact comparison

h1 = a[β0 + Ω0x], with β0 = (0, −1, −2)T and Ω0 = (1, 1, 1)T.

β1=[−0.2−0.5−0.8],Ω1=[1−221−221−22]

h2 = a[β1 + Ω1h1], and y = β2 + Ω2h2, with β2 = 0 and Ω2 = (1, −2, 2). The three thresholds are fixed at 0.2, 0.5, and 0.8 throughout the story.

The joints are 0.2, 0.5, 0.8, 1, 1.2, 1.5, 1.8, 2.2, 2.5, 2.8. Their nonzero slope jumps are 1, −2, 2, −2, 2, −2, 1, 1, −2, 2. Thus all ten are genuine joints, and a shallow ReLU network with an affine output needs at least ten hidden units. Weighting hinges at those ten positions by these jumps reproduces the curve exactly.

For a dense network, every connection weight and every non-input bias counts, including zeros and repeated values chosen here. The deep architecture has 3 + 3 + 9 + 3 + 3 + 1 = 22 parameter slots. Shallow width ten has 10 + 10 + 10 + 1 = 31. This compares exact representations of this structured curve; it is not a claim that 22 parameters can specify any ten joints independently.
