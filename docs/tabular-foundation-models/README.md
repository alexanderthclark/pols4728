# Tabular foundation models

Buildless scroll-driven course lesson for POLS 4728, following Christoph Molnar's *Tabular Foundation Models*. White textbook layout, Latin Modern type, course palette, torso-less hero illustration. The bear-survival task is the running example throughout all 26 scenes: the true depth-two data-generating tree, labeled context, global network weights, synthetic task pretraining, simplified row/column attention, exact Bayesian updating, and seven scenes diagnosing the interaction for XGBoost.

Run `npm run build` to regenerate the no-JavaScript reading version, `npm test` for Bayesian arithmetic and reversible visual-state checks, and `npm run dev` for a local preview. Source files in this directory are served directly. All core teaching points are reached by native scrolling; chapter links offer shortcuts. `?motion=reduce` or system reduced-motion preference uses complete visual states at logical thresholds.

## Numerical example

Two possible bear-survival worlds, with equal prior mass. World A assigns survival probability p = logistic(1) to matching pairs (black-and-fight or brown-and-lie-down), and 1 − p to mismatches; world B reverses them. These are the same population probabilities used in the later simulation. Outcomes are independent given the shared world and fixed features. A separate small context accumulates 0, 1, 2, then 4 brown-and-lie-down survivors. After n such observations, the posterior probability of A is logistic(n), and predictive survival for another matching encounter is (1 − p) + (2p − 1)·logistic(n). With four observations these are 98.2014% and 72.2747%, respectively. No TabPFN model is run. Animation interpolation is visual interpolation between exact results, not fractional-data Bayesian updating. Other probability bars are schematic.

## Bear experiment

The bear chapter separates population probabilities, measured XGBoost results, and a proposed explanation for TabPFN. `bear-results.mjs` is generated by `../../examples/tabular-foundation-models/bear_diagnostics.py`; the SVG plot consumes its exact means. The reading version includes depth-two and depth-six results, seed standard deviations, Brier scores, and reproduction links. The simulation uses independent binary bear/strategy features, three uniform distractors, and logistic outcome noise. It yields 73.1059% versus 26.8941% survival by response match. No TabPFN inference or attention measurement is represented as an observed result.

The plotted variants hold labels and splits fixed within each seed: no distractors; continuous distractors; binarized distractors; two histogram bins; and an added feature product. Full CSV/JSON results and dependency versions are tracked with the script. `npm test` checks reported summaries against all per-seed records, exact chart data, original scene routing, and deterministic reversible visual states.
