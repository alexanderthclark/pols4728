01 / THE TRAINING SAMPLE

Five games are all it has.

An alien watches the Knicks play the Spurs. It sees the final scores and who won, but it does not know the rule that connects them.

We give it one input: Knicks points minus Spurs points, called x. A Knicks win is y = 1; a loss is y = 0. The five observed games are its training sample.

The alien is learning from final scores. It is not trying to forecast a game before it is played.

02 / THE LEARNING RULE

It puts a boundary in the gap.

The closest observed loss is −4. The closest observed win is +1. The alien puts its cutoff halfway between them: −1.5.

It now predicts a win whenever x is at least −1.5. All five training outcomes fall on the correct side of that boundary.

We will give every alien this same learning procedure. Only the games it observes will change.

03 / A NEW GAME

The fit is perfect. The rule is wrong.

Now show the alien a game in which the Knicks lost by one point. At x = −1, its learned rule predicts a win.

The true boundary is zero. For −1.5 ≤ x < 0, the learned rule makes the same error: the alien calls it a win even though the Knicks did not outscore the Spurs.

The correct boundary was available in the model class. The sample simply did not pin it down.

04 / REPEATED TRAINING

Different games, different boundaries.

Imagine repeating the experiment with other aliens. Each learns from its own five games, using exactly the same procedure.

The figure shows three independently drawn samples. Different observations lead to different fitted cutoffs. One alien sees five wins and no losses, so it puts its cutoff at −∞ and predicts a win for every finite point differential.

Select another sample to inspect its games.

How we generate the games

These are synthetic games. Draw each team’s score independently and uniformly from the integers 0 through 100, then add half a point to the Knicks’ score to prevent ties.

For a sample containing only wins, use cutoff −∞; for only losses, use +∞. These rules predict the observed outcome for every finite input. Otherwise, use the midpoint cutoff and classify equality with it as a win.

05 / ONE FIXED INPUT

Ask them the same question.

The Knicks lead by half a point. Who wins?

Hold this test input fixed at x0 = +0.5. The true outcome is always y0 = 1, but the aliens’ learned rules need not agree.

The same vertical test line passes through each fitted rule. Different answers now reflect different training samples, rather than different test games.

06 / A POPULATION OF FITTED RULES

Repeat the training 1,000 times.

Give 1,000 aliens independent five-game samples and ask each about that same half-point lead.

In our worked simulation, 468 predict a loss and 532 predict a win. Each mark in the figure represents one independently trained alien.

We are about to change the horizontal axis. It will show each alien’s prediction, either zero or one, rather than the game’s point differential.

07 / EXPECTATION

The average lives between their answers.

Gather the aliens by their predictions: 468 at zero and 532 at one. Their average prediction is 0.532.

An expectation over training samples averages the predictions we would get from all possible datasets, each fitted by the same learning rule. Our 1,000-alien average estimates that expectation.

No individual alien gives the answer 0.532. It is the average across fitted rules at one fixed input.

𝔼𝒟[f^𝒟(x0)]≈0.532

08 / BIAS

Measure from the truth to the average.

The true outcome is one. The average prediction is 0.532, which is 0.468 below it.

Bias is the expected prediction minus the truth. Our estimate is therefore −0.468; its square is approximately 0.219.

At this input, an alien’s prediction can be too low, but cannot exceed one. The errors do not cancel when we average them.

09 / VARIANCE

Measure each answer from the average.

Keep the same predictions and the same mean. This time, measure how far each prediction lies from 0.532.

The 468 loss predictions are 0.532 below the mean. The 532 win predictions are 0.468 above it. Square those distances and average them to estimate variance: approximately 0.249.

This is how the fitted prediction changes across training samples, at the same test input.

10 / MEAN SQUARED ERROR

Now measure each answer from the truth.

The 532 win predictions are correct, so their squared errors are zero. The 468 loss predictions are one unit from the truth, so their squared errors are one.

Average over all 1,000 aliens. Mean squared error is 468 / 1,000 = 0.468.

The predictions have not changed. We have changed the reference point: from their mean, for variance, to the true outcome, for MSE.

11 / THE DECOMPOSITION

Two parts account for the same error.

Squared bias measures how far the average prediction is from the truth. Variance measures how much the individual predictions spread around that average.

Together they account for the MSE: approximately 0.219 + 0.249 = 0.468. Irreducible outcome noise is zero here, because the final score differential determines the winner.

Random training samples can produce both bias and variance even when there is no outcome noise.

The exact worked values

Squared bias is 0.219024 and variance is 0.248976. Their sum is 0.468. These are Monte Carlo estimates, but the decomposition holds for this finite population of predictions, using divisor 1,000 for variance.

12 / EXPLORE

Give the aliens more experience.

Change the number of training games, or move the fixed test input. The same prediction stacks, mean, and error decomposition update together.

We have repeated one learning procedure, rather than compared models of different complexity. This example demonstrates a bias–variance decomposition; a complexity tradeoff is a separate question.

Why the binary predictions give this result

At +0.5, let q be the probability that a newly trained alien predicts a loss. Its average prediction is 1 − q, its bias is −q, and its prediction variance is q(1 − q). Thus MSE = q² + q(1 − q) = q.

This relationship comes from hard predictions in {0, 1} at a point where the truth is one. It is not a general claim that higher variance causes greater bias.
