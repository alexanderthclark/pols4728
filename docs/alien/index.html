Five games

01 / ONE ALIEN

What determines who wins?

An alien watches five games between the Knicks and the Spurs. It sees the final scores and the winner, but does not know the rules of basketball.

Let x be Knicks points minus Spurs points. Code a Knicks win as y = 1 and a loss as y = 0. The alien tries to learn the rule connecting them.

This is a task about learning from final scores. The input is already known after the game.

02 / THE LEARNED RULE

Place a cutoff between loss and win.

The alien places its cutoff halfway between the closest observed loss and the closest observed win. Here those point differentials are −4 and +1.

c^=−4+12=−1.5

It predicts a Knicks win at or above −1.5, and a loss below it. This rule classifies all five training games correctly.

03 / THE TRUE RULE

A perfect fit can still miss the rule.

The true cutoff is zero: the Knicks win exactly when their final score is higher. At x = −1, the alien predicts a win even though the Knicks have lost by one point.

The true rule is available within this model class. Five games simply may not reveal its cutoff.

Random training data can produce estimation error even when the outcome is deterministic given the input.

04 / MANY ALIENS

Give each alien its own five games.

Imagine 1,000 aliens, all using the same learning rule. Each observes an independent training sample of five games. Different samples produce different cutoffs.

For the simulation, draw each team’s score independently and uniformly from the integers 0 through 100. Add half a point to the Knicks’ score to prevent ties. These are synthetic games.

If an alien sees only wins or only losses, it predicts that observed outcome for every input.

The figure shows the first 48 aliens. The calculations use all 1,000.

05 / ONE FIXED QUESTION

Ask every alien about the same game.

Hold the test input fixed at x0 = 0.5. The Knicks lead by half a point, so the true outcome is always y0 = 1.

Each alien applies its own fitted rule to this same input. Some predict a win; others predict a loss.

This isolates variation across training samples. Changing the test game would answer a different question.

06 / EXPECTATION

Average over the aliens.

In this simulation, 532 aliens predict a win and 468 predict a loss. Their average prediction is 0.532.

The expectation 𝔼𝒟 averages over possible training datasets 𝒟, each passed through the same learning rule. The aliens make those repeated fits visible.

Our finite average estimates that expectation. No individual alien predicts 0.532: each prediction is either zero or one.

07 / BIAS

Compare the average with the truth.

Bias at this fixed input is the expected prediction minus the true outcome. Our estimate is 0.532 − 1 = −0.468.

The predictions can be too low here, but cannot be greater than one. Their errors therefore do not cancel when we average over aliens.

Squared bias is (−0.468)² = 0.219024. This is bias from finite-sample learning, even though the correct cutoff belongs to the model class.

08 / VARIANCE

Measure spread around the average.

Variance asks how much a prediction at the same input changes across training samples. Measure each prediction’s squared distance from the average prediction, then average those distances.

The win predictions are 1 − 0.532 = 0.468 above the mean; the loss predictions are 0 − 0.532 = −0.532 below it. The estimated variance is 0.248976.

This is the variance of the fitted predictions, rather than the variance of the final-score differential.

09 / THE DECOMPOSITION

Account for the prediction error.

A win prediction has squared error zero. A loss prediction has squared error one. The average squared error is therefore the fraction of aliens predicting a loss: 0.468.

It equals squared bias plus variance. Irreducible noise is zero because the winner is fixed once the final score differential is given.

These numbers are Monte Carlo estimates. Their decomposition holds for the simulated predictions themselves, using divisor 1,000 for the variance.

10 / EXPLORE

Change the training sample size.

Give the aliens more games and repeat their training. Keep the test input fixed to compare predictions at the same point. Or move the test point to see where the learned rules make mistakes.

This example demonstrates bias and variance in one learning rule. It does not compare models of different complexity, so it does not demonstrate a bias–variance tradeoff.

The same result in symbols

Let q be the probability that a newly trained alien predicts a loss at x0 = 0.5. The mean prediction is 1 − q, bias is −q, and variance is q(1 − q). Thus MSE = q² + q(1 − q) = q.

This relationship comes from hard predictions in {0, 1} at a point where the truth is one. It is not a general claim that higher variance causes greater bias.
