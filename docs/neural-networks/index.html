01 / A shallow network

Start with a straight line.

There is just one input, x, so the network’s output is a curve on an ordinary two-dimensional plot. Start with f(x) = x: one straight piece, with the same slope everywhere.

We will keep the input one-dimensional throughout. What changes is how the network transforms it.

A ReLU clips the negative part.

The rectified linear unit, or ReLU, returns its input when that input is positive and returns zero otherwise.

ReLU(x) = max(0, x)

The result has two straight pieces meeting at a joint. Here, that joint is at x = 0.

Move the joint. Change the slope.

A hidden neuron can compute ReLU(x − t). Its bias places the joint at t; keep scrolling to move that joint across the plot. An output weight, a, multiplies the resulting hinge.

a ReLU(x − t)

Before t, this contribution is zero. After t, its slope is a. A negative output weight makes the contribution slope downward.

One neuron starts the climb.

Place the first joint at −1 and give its neuron an output weight of +1. The function is flat until −1, then starts rising.

f(x) = ReLU(x + 1)

The color connects the neuron in the network diagram to the contribution it makes on the function plot.

A second neuron turns it downward.

Add a neuron with its joint at zero and output weight −2. The first neuron keeps contributing a slope of +1. Once the second activates, the total slope becomes +1 − 2 = −1.

f(x) = ReLU(x + 1) − 2 ReLU(x)

Neurons contribute to a sum. They do not take turns owning separate segments.

A third neuron flattens it again.

A final neuron activates at +1 and adds a slope of +1. The total slope returns to zero. Three hinges now make a hill.

f(x) = ReLU(x + 1)− 2 ReLU(x) + ReLU(x − 1)

The slope across the four intervals is 0, +1, −1, and 0. Each joint changes the slope of the sum.

That is a shallow neural network.

The input feeds one hidden layer of ReLU neurons. A linear output adds their weighted activations and an output bias.

f(x) = c + ∑j aj ReLU(wjx + bj)

With one input, each hidden neuron can introduce at most one joint. Increasing the layer’s width gives us more possible places to bend.

02 / What depth changes

A layer can bend an already-bent function.

Consider a tent on the interval [0, 1]. Two ReLU neurons make it rise to one and fall back to zero:

T(s) = 2 ReLU(s) − 4 ReLU(s − ½).

One hidden layer produces two linear pieces and one interior joint. Now feed this tent into another copy of the same transformation.

The next layer sees the tent twice.

As x crosses [0, 1], the first tent’s output travels from zero to one and back to zero. Applying T again creates a smaller tent along each of those journeys.

f(x) = T(T(x))

Two hidden layers, still only two neurons per layer, produce four linear pieces and three interior joints.

Composition multiplies the pieces.

The third layer applies the same transformation to each rise and fall. Four pieces become eight, and three joints become seven.

In a shallow network, a neuron responds directly to x. Here, its input is an already-bent function of x, which can cross the neuron’s activation threshold many times.

Five layers. Thirty-one joints.

For this construction, d hidden layers create 2d linear pieces and 2d − 1 interior joints on [0, 1]. Five layers use ten hidden neurons to create thirty-two pieces.

This is an example of what carefully chosen weights can express. Depth does not automatically create this many joints, or make a fitted network better.

03 / Approximation by adding joints

Return to one hidden layer.

Our target is now the smooth function sin(x) on [0, 2π]. The network traces straight segments through selected points on the sine wave, with five interior joints.

One neuron supplies the initial slope across the whole interval. Five more supply the changes in slope. That makes six hidden neurons, all in one layer.

The network already resembles the sine wave. Look between its joints to see what it misses.

Zoom into the gap.

The sine curve bends continuously while the network follows a straight segment. The highlighted vertical gap is the approximation error at a particular input.

We can make that gap smaller by giving the network another place to change its slope.

Add a joint at that input.

Insert the point on the sine curve and replace the old segment with two new ones. At the selected input, the approximation now meets the target exactly.

The network gets one new hidden neuron. We also update the affected existing output weights, because they encode the changes between adjacent slopes.

Adding a neuron alone is not a guarantee of improvement. Here, we explicitly choose its location and recompute the weights.

Keep adding places to bend.

As you scroll, the single hidden layer widens from seven neurons to twenty-six. More joints divide the curve into shorter straight segments, and the approximation error shrinks.

The network diagram becomes crowded while the approximation becomes visually smooth. Up close, its segments are still straight: a finite ReLU network remains piecewise linear.

Enough width can approximate a continuous curve.

This construction illustrates the basic idea behind universal approximation. A continuous function on a closed, bounded interval can be approximated uniformly as closely as we want by a sufficiently wide, one-hidden-layer ReLU network.

Choose a fine enough collection of points, connect them by straight segments, and express each change in slope with a ReLU. Continuity keeps the curve and those segments close across the whole interval.

The statement concerns what a network can represent. It does not tell us how many data points we need, whether training will find the required weights, or how well the network will predict outside the interval.
