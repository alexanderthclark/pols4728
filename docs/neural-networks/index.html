01 / A shallow network

A linear equation, drawn as a network.

ŷ = wx + b = x + 0.5

The arrow from x has weight w = 1. The faint constant-1 node adds the intercept b = 0.5; it is not a second observed feature.

Bias connections disappear from the drawing for clarity. The intercept remains part of the equation and the model.

A ReLU clips the negative part.

ReLU keeps positive inputs and clips negative inputs to zero, creating a joint at zero.

ReLU(x) = max(0, x)

Move the joint. Change the slope.

First move the joint with t. Then change a to steepen the slope and turn it downward.

a ReLU(x − t)

The contribution stays zero before t. Faint dashed curves show comparison examples.

One neuron starts the climb.

The first neuron activates at −1, adding +1 to the slope.

f(x) = ReLU(x + 1)

A second neuron turns it downward.

The second activates at zero and adds −2 to the slope: +1 − 2 = −1. Both neurons keep contributing.

f(x) = ReLU(x + 1) − 2 ReLU(x)

A third neuron flattens it again.

The third activates at +1 and adds +1, returning the total slope to zero.

f(x) = ReLU(x + 1)− 2 ReLU(x) + ReLU(x − 1)

That is a shallow neural network.

One hidden layer computes the ReLUs. A linear output adds their weighted activations and a bias.

f(x) = c + ∑j aj ReLU(wjx + bj)

02 / What width changes

One neuron, one place to bend.

The width is the number of neurons in our single hidden layer. One neuron can introduce at most one joint, dividing the input interval into two linear pieces.

A second neuron adds another joint.

Add a second neuron with a different threshold. The output sums both hinges: two joints, three linear pieces.

Three neurons, four straight pieces.

A third neuron adds another slope change. All three receive the same scalar input in parallel, producing three joints and four linear pieces.

A wider layer allows more joints.

The layer widens from three neurons to six, giving this example six joints and seven linear pieces.

In general, width m allows at most m joints and m + 1 pieces. Inactive units, zero weights, coincident joints, or cancellation can reduce the count.

03 / Approximation by adding joints

Approximate a smooth target.

Approximate sin(x) on [0, 2π] with the same shallow architecture. Six hidden neurons supply the initial slope and five joints, joining selected points with straight segments.

Zoom into the gap.

Between joints, the straight segment misses the curved target. The vertical gap is the error at this input.

Add a joint at that input.

Add a joint on the sine curve at the marked input. One new neuron, plus updated existing output weights, replaces one segment with two and makes the error zero here.

Keep adding places to bend.

The layer widens from seven neurons to twenty-six. Shorter segments approach the sine curve; the result looks smooth but remains piecewise linear.

Enough width can approximate a continuous curve.

A continuous function on a closed, bounded interval can be approximated uniformly as closely as we want by a sufficiently wide, one-hidden-layer ReLU network. Continuity lets sufficiently fine straight segments stay close throughout the interval.

This guarantees that suitable weights exist. It does not guarantee that training finds them, specify data requirements, or justify predictions outside the interval.
