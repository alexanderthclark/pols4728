01 / 16

The observed outcomes form a fixed vector

Begin with the three-observation picture. At inputs x = (1, 2, 3), the observed outcomes are y = (1, −1, 1). Every fitted function supplies three predictions:

F = (F(x₁), F(x₂), F(x₃)).

Those predictions place the model at a point in prediction space. Each axis corresponds to an observation, rather than an input feature. The outcome vector y stays fixed while the model moves.

For half-squared-error loss, the remaining displacement is r = y − F. Its norm measures the remaining prediction error:

L(F) = ½‖y − F‖²,
∇L(F) = F − y.

Move through the fitted trees to see the prediction, gradient, and norm change together. Each new tree fits the current residuals. The arrow labelled r = −∇L points toward y.

The zero starting function keeps this picture simple. The worked calculation below starts at the outcome mean. This three-axis view is an orthographic projection; the displayed norms and losses use the full vectors. Vector readouts are rounded for display.

02 / 16

A tree approximates the negative gradient

The desired change is −∇L(F) = y − F. We cannot independently set every prediction when the next learner is a small tree. Fit a stump to these negative-gradient targets and add a scaled correction.

At the zero model, the first stump predicts h₁ = (1, 0, 0). With learning rate α = ½, its update is

F₁ = F₀ + ½h₁ = (½, 0, 0).

The residual becomes (½, −1, 1). Its norm falls from √3 to 3/2, so half-squared loss falls from 3/2 to 9/8.

Use the correction slider to move from the starting model to the updated prediction. The observed outcomes stay fixed, and the gradient is recalculated at the displayed prediction. The tree remains the one fitted at the start of this step.

The figure uses the round and learning rate selected in the preceding view. These numbers describe its initial setting.

03 / 16

The norm defines an equal-loss radius

Now look at an exact two-dimensional slice of prediction space. The starting prediction and the fixed outcome vector lie in this plane. A circle centered at y, with radius R = ‖y − F‖, passes through the starting prediction.

Every point on that circle has the same half-squared loss. An update that lands inside it reduces the remaining norm and the loss; an update outside it increases them. The negative gradient points directly toward the center.

Adjust a candidate direction and its step length. The step slider reports ‖Δ‖/R. Both orientations of the line are shown. If h makes an obtuse angle with the negative gradient, reverse it to use −h. At 90°, neither sign offers a decreasing step. A direction that points inward can still overshoot if the step is too long.

L(F + Δ) = ½‖y − F − Δ‖².

Changing the starting prediction changes the radius. The radius, gradient norm, and loss are calculated from the same underlying vectors; this flat slice uses equal scales, so its distances are exact.

This direction experiment does not replace the fitted trees. A nonzero mean-residual tree already has an improving orientation. The next example shows what happens when the remaining residual cannot be represented by any tree.

04 / 16

Identical inputs restrict every update

Suppose we have two observations with identical predictor values but different outcomes: x₁ = x₂ = 1, with y = (1, 0). Any regression tree using only x must assign them the same prediction. So must a sum of those trees:

f = (f(x₁), f(x₂)) = (c, c).

Every possible prediction lies on the 45-degree line through the origin. The target y = (1, 0) lies off that line. We keep the same half-squared-error loss, so the negative gradient is exactly the residual r = y − f.

Start from f₀ = (0, 0) with learning rate 1. The residual is (1, 0). A tree cannot split the identical inputs, so its best residual prediction is their average: h₁ = (½, ½). Adding this correction gives f₁ = (½, ½).

This is the orthogonal projection of the target onto the equal-prediction line. The remaining residual is (½, −½), perpendicular to every available update (a, a). Its mean is zero, so the next fitted tree is h₂ = (0, 0), even though the loss gradient is still nonzero.

L(c, c) = ½[(1 − c)² + c²]
= (c − ½)² + ¼.

The best attainable half-squared training loss is ¼. Move the shared prediction c to inspect the residual and next fitted tree; “Add fitted tree” takes the unit-rate step to the projection. At the projection, the equal-loss circle touches the diagonal, and no tree using only x can move inside it.

The negative gradient tells us where we would ideally move, while the weak learner determines which directions are available. Boosting fits a representable approximation to that gradient; when the gradient itself is representable, the two directions can coincide.

Starting at zero exposes the update. Initializing at the outcome mean would already place this model at (½, ½).

Start with a loss and a constant prediction

Apply this geometry to a full gradient-boosting calculation. We now use four observations and a mean starting prediction, following the example from section 1.4.3 of the boosting notes: one predictor x, with outcomes y = (0, 2, 1, 5) at x = (1, 2, 3, 4). Squared-error boosting starts at the best constant prediction, the outcome mean:

F₀(x) = (0 + 2 + 1 + 5) / 4 = 2.

The prediction vector is z₀ = (2, 2, 2, 2), and its total half-squared loss is ½(4 + 0 + 1 + 9) = 7. This loss sums over the observations; it is not a mean squared error.

The figure shows the input x and the observed response. Each blue prediction will change as we add trees; the black observed outcomes stay fixed. We use half-squared-error loss to make every gradient and update explicit.

The calculations below use α = 1. Changing the learning rate refits each subsequent tree to its new negative-gradient targets.

06 / 16

Calculate the negative gradient

Write zᵢ = F(xᵢ) and regard the total loss as a function of the four prediction values:

L(z) = ½ Σᵢ₌₁⁴ (yᵢ − zᵢ)².

Hold the observed inputs and outcomes fixed. Changing the prediction zᵢ changes its contribution to the loss, giving

∂L / ∂zᵢ = zᵢ − yᵢ.

For example, the fourth derivative is ½ · 2(5 − z₄)(−1) = z₄ − 5. Each partial derivative varies one prediction while holding the other three fixed.

At the initial model, the gradient is g₁ = (2, 0, 1, −3). Its negative gives the pseudo-residual targets y − z₀ = (−2, 0, −1, 3). For observation 4, the gradient entry is 2 − 5 = −3: increasing that prediction initially reduces loss.

The derivative is with respect to a prediction, not the input x or a tree’s split threshold. For this loss, the pseudo-residuals equal ordinary residuals. Other losses give different targets. The next step is to turn these four desired corrections into a function of x.

07 / 16

Fit a tree to the negative gradient

The gradient supplies a target at each training observation. A tree supplies a correction that we can also evaluate at a new input. Here the tree is a stump: one split and two leaf values. For each candidate split, fit the mean residual on each side, then compare Σᵢ(rᵢ − h(xᵢ))². This is the residual-fitting SSE used to choose the tree.

There are three possible training partitions, represented by cuts at 1.5, 2.5, and 3.5. Their fitted SSEs are 26/3, 10, and 2. The cut at 3.5 wins.

Left mean = (−2 + 0 − 1) / 3 = −1;
right mean = 3.

The fitted correction is h₁ = (−1, −1, −1, 3). It approximates the negative gradient with two shared leaf corrections. The four negative-gradient targets ask for individual changes; a stump cannot supply four independent values. With squared error, each mean residual also minimizes the original loss within its leaf.

Inspect another candidate in the figure to see its leaf means and SSE. This comparison does not replace the fitted winner in the ensemble.

08 / 16

Scale and add the fitted correction

With α = 1, add the fitted correction to each current prediction:

z₁ = z₀ + h₁
= (2, 2, 2, 2) + (−1, −1, −1, 3)
= (1, 1, 1, 5).

The new loss is ½(1 + 1 + 0 + 0) = 1, down from 7. Observation 2 started with a correct prediction of 2 and now receives 1. The shared correction worsens that individual prediction while improving the aggregate fit.

The tree is also a descent direction: g₁·h₁ = −12 < 0. Along it, the exact loss is L(z₀ + αh₁) = 7 − 12α + 6α², minimized at α = 1. A useful direction still requires an appropriate step size.

09 / 16

Recompute before fitting tree two

Evaluate the loss gradient at the updated predictions. It is now (1, −1, 0, 0), so its negative gives fresh pseudo-residuals:

y − z₁ = (−1, 1, 0, 0).

Repeating the candidate comparison now gives SSEs 2/3, 2, and 2. The best cut has moved to 1.5. Its left leaf contains −1, while its right leaf predicts (1 + 0 + 0) / 3 = 1/3.

The second correction is therefore h₂ = (−1, 1/3, 1/3, 1/3). Tree one stays fixed; tree two learns what is still missing from the ensemble.

At α = 1/2 the residuals and second tree differ. The cuts at 1.5 and 3.5 tie; the implementation selects the first cut in increasing order.

10 / 16

Add the second correction

Add tree two with α = 1:

z₂ = z₁ + h₂
= (0, 4/3, 4/3, 16/3).

The remaining residuals are (0, 2/3, −1/3, −1/3), so the total half-squared loss is ½(0 + 4/9 + 1/9 + 1/9) = 1/3. Across the two updates, loss falls 7 → 1 → 1/3.

Observation 4 was exactly right after tree one. It now moves from 5 to 16/3, because it shares tree two’s right-leaf correction. Boosting reduces a total loss; it need not improve every observation on every round.

Each gradient-boosting round follows the same sequence: compute a negative gradient, approximate it with a fitted tree, add a scaled correction, and recompute. These calculations establish training-loss reductions; performance on new observations still requires validation.

11 / 16

Recompute the gradient after every tree

Continue from the same constant model. At round m, evaluate the current ensemble on the training data, compute a fresh negative gradient, fit the next tree, and add its scaled correction.

rₘᵢ = yᵢ − Fₘ₋₁(xᵢ),
Fₘ(x) = Fₘ₋₁(x) + αhₘ(x).

Move through the rounds to see the cumulative prediction. The earlier trees stay fixed; each new tree fits what the current ensemble still needs. Changing α changes the residual targets and can change later splits.

At a new input, prediction uses the same fitted functions: Fₘ(x) = 2 + αΣₖ₌₁ᵐ hₖ(x). We add their outputs, rather than choosing one tree or taking a vote.

This figure reports training loss. The learning rate, tree complexity, and number of rounds govern how the model grows. Performance on new observations needs validation; more rounds can fit noise.

12 / 16

The loss defines the learning targets

For a differentiable loss ℓ(y, z), gradient boosting starts from a constant that minimizes total loss, when a finite minimizer exists. Otherwise, constrain the starting constant to a finite closed interval or use a suitable penalty. Each round then computes

rₘᵢ = −∂ℓ(yᵢ, z)/∂z
evaluated at z = Fₘ₋₁(xᵢ).

These pseudo-residuals describe the desired change at each training prediction. Fit a regression tree to them to choose its regions. Within each region, choose a leaf correction that minimizes the original loss when added to the current model. Use a learning rate 0 < α ≤ 1 to scale the correction tree, add it, and differentiate again.

For half-squared error, both calculations simplify: pseudo-residuals are ordinary residuals, and the optimal leaf correction is their mean. For other losses, the gradient targets and final leaf values can differ.

The tree is a constrained approximation to a gradient direction. Gradient boosting therefore performs stagewise optimization over functions that the chosen trees can represent.

13 / 16

A residual is no longer the learning target

Keep the regression problem and change the loss. The new example has x = (1, …, 7) and y = (0, 0, 1, 2, 3, 4, 15). The unusually high seventh outcome lets us see how the loss controls its influence. You can also return to the original four observations.

Write the ordinary residual as e = y − z. Squared error gives the negative-gradient target e. Huber loss is quadratic near zero and linear in the tails, giving

−∂ℓδ/∂z = clip(e, −δ, δ).

At the Huber-optimal constant F₀ = 2, the last residual is 13 but its target is 1 when δ = 1. Its influence on the split search is bounded. With asymmetric squared loss, underprediction and overprediction instead receive different weights:

−∂ℓτ/∂z = 2τe if e ≥ 0;
2(1 − τ)e if e < 0.

At τ = 0.8, an equally large underprediction receives four times the gradient magnitude of an overprediction. This loss estimates an expectile, rather than a quantile. At τ = 0.5, it becomes our half-squared loss.

Changing the loss refits both paths from the same loss-optimal constant. At later rounds this target comparison uses the current gradient-boosted model. The earlier Euclidean circles describe squared error only.

Different targets can select a different split

The next stump still uses least squares to approximate its training targets. Compare the split search using ordinary residuals with the split search using the selected loss’s negative gradients. Each column reports its own target-fitting SSE; their numerical scales need not agree.

At the initial seven-point Huber model with δ = 1, raw residuals select a cut at 6.5, isolating the outcome of 15. The negative-gradient targets (−1, −1, −1, 0, 1, 1, 1) select 3.5. Clipping changes which observations drive the partition, even though the data and current predictions are identical.

This is where the gradient calculation matters for tree structure. Averaging raw residuals and calling the result “Huber boosting” would continue to select splits for the squared-error objective.

Cuts 3.5 and 4.5 tie in the initial Huber gradient fit; the first split wins ties in ascending order. At every round, both split searches use the same current gradient-boosted prediction. This isolates the effect of changing the targets. A gradient-selected split need not produce the largest possible one-round reduction in the original loss.

15 / 16

Choose leaf values using the original loss

The fitted gradient tree determines two regions. Its mean target in each region describes the gradient approximation, but the prediction correction has a separate job. Choose the correction c that minimizes the selected loss within that region:

cⱼ = arg minc Σi ∈ Rⱼ ℓ(yᵢ, F(xᵢ) + c).

For the initial Huber split at 3.5, the target means are −1 and 3/4. The loss-minimizing prediction corrections are instead −5/3 and 3/2. The curves show the original leaf losses and mark both values. The learning rate scales the minimizing corrections afterward.

Squared error makes both values the mean residual. Huber corrections solve Σ clip(eᵢ − c, −δ, δ) = 0; asymmetric squared corrections solve the corresponding weighted residual equation. Changing the loss can therefore change both the tree’s regions and the sizes of its updates.

The curves use the next gradient-selected stump at the chosen round. Huber can have an interval of minimizing corrections; the calculation chooses its midpoint.

Both methods start at the same constant and use the same learning rate and stump size. Gradient boosting fits the negative gradients and recalibrates its leaves with the chosen loss. The residual shortcut fits y − F and adds the mean residual in each leaf.

Move through the rounds and switch losses. Under squared error, the paths coincide. Other losses can produce different splits, corrections, predictions, and training-loss histories. The graph evaluates both paths with the currently selected loss; loss values across different loss choices are not directly comparable.

These are finite sequences of greedy fits, so the gradient path need not have lower loss at every round. A large residual can still eventually be fitted under Huber loss, especially when a tree can isolate it. Clipping its gradient does not exclude that observation from the model.

Select “Identical inputs” for a sharper distinction. The three responses are (0, 0, 10), all at x = 1, so every tree must give them one shared prediction. With Huber δ = 1, the best constant is 1/2. Gradient boosting stays there. The residual shortcut moves toward the response mean, 10/3, and increases Huber loss. A zero mean residual does not imply a zero gradient for this loss.

Forward stagewise optimization can itself minimize a general loss. The comparison here isolates the ordinary least-squares residual-fitting shortcut. The useful generalization is to derive the target and leaf update from the objective we actually want to optimize.

BEYOND SQUARED ERROR

Change the loss, change the gradient

Fitting ordinary residuals works for half-squared-error loss because its negative derivative is y − z. Gradient boosting uses the derivative of the chosen loss, which need not have that form.

Losses and their negative-gradient targets (e = y − z)
Lossℓ(y, z)−∂ℓ/∂z
Half-squared error½(y − z)²y − z
Huber½e² if |e| ≤ δ;
δ|e| − ½δ² otherwise		clip(e, −δ, δ)
Asymmetric squaredτe² if e ≥ 0;
(1 − τ)e² otherwise		2τe if e ≥ 0;
2(1 − τ)e otherwise
Exponential, y ∈ {−1, +1}exp(−yz)y exp(−yz)

In the binary-classification row, z = F(x) is an additive score. Its sign predicts the class. A positive observation with score 0 has target +1; with score −2, its target is exp(2), about 7.39. A confidently wrong prediction asks for a larger correction. These targets come from the loss derivative, rather than the difference between a class label and its score.

For a tree region Rₘⱼ, the final leaf correction is chosen using the original loss:

cₘⱼ = arg minc Σxᵢ ∈ Rₘⱼ ℓ(yᵢ, Fₘ₋₁(xᵢ) + c).

For exponential loss, a leaf containing only one class has no finite unpenalized minimizer: the loss approaches zero as the score grows in that class’s direction, but never reaches zero at a finite score. Constraining the correction to a finite closed interval, or adding a positive quadratic penalty, gives a finite minimizer.

The fitted pseudo-residual tree defines the regions; these corrections define hₘ. The learning rate then scales the tree’s contribution. Squared error makes cₘⱼ the mean residual; that shortcut does not apply to every loss.

How XGBoost extends the calculation

XGBoost uses first and second derivatives to choose trees with a quadratic loss approximation and penalties on leaf values and tree complexity. For a fixed structure, with penalty ½λΣⱼwⱼ² and no L1 penalty, the leaf value that minimizes this quadratic approximation is wⱼ* = −Gⱼ/(Hⱼ + λ), provided Hⱼ + λ > 0. Here G and H sum the gradients and second derivatives in the leaf.

For our half-squared-error loss, this becomes Σrᵢ/(nⱼ + λ). With λ = 0 it is the mean residual. The learning rate scales the fitted tree afterward. XGBoost is one extension of the gradient-boosting idea; the worked calculation above uses ordinary least-squares stumps.
