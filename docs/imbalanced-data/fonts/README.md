# Latin Modern Roman

These unmodified OpenType fonts are from Latin Modern 2.005, by Bogusław
Jackowski and Janusz M. Nowacki, based on Donald E. Knuth’s Computer Modern.
Copyright 2003–2021 by B. Jackowski and J. M. Nowacki on behalf of TeX Users
Groups. They are distributed under the accompanying GUST Font License.

The subset used here contains:

- `lmroman10-regular.otf`
- `lmroman10-italic.otf`
- `lmroman10-bold.otf`

The complete upstream package, sources, and manifest are available from
[the Latin Modern project](https://www.gust.org.pl/projects/e-foundry/latin-modern).
