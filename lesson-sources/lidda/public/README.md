# LiDDA: how attention assigns credit

This directory contains the generated static lesson. Edit and rebuild the [lesson source](../../lesson-sources/lidda/) rather than changing bundled assets.

From `lesson-sources/lidda/`, run `npm ci`, `npm test`, `npm run typecheck`, and `npm run publish:static`. Commit the source and generated page together. The existing GitHub Pages workflow publishes `docs/` after changes are merged to the publishing branch.

All runtime assets and math fonts are local. See `THIRD-PARTY-LICENSES.txt` for dependency and font notices.
